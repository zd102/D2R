# 黯蚀 II · ECLIPSE

底材现支持 D2R 原生词条、超强品质与无形生成，地面显示超强、无形和孔数；底材属性无需鉴定，制作符文之语与重载保留原值。数据、概率和获取范围见 [底材生成规则](docs/base-properties.md)。

可在本地浏览器游玩的暗黑风格单人 ARPG，借鉴《暗黑破坏神 2》的等距视角、战斗与刷装备循环。五幕战役改编为五章、每章五关，包含普通、噩梦和地狱三个难度；不是原作引擎、地图及全部内容的复刻，没有使用暴雪原版素材。完整关卡、任务与推进规则见 [五幕战役](CAMPAIGN.md)。

角色系统支持经典《毁灭之王》的圣骑士、亚马逊和法师，各有三系 30 技能、独立属性成长及专属装备限制。包含四维属性、1 至 99 级、技能协同、召唤、灵气和护盾、十个穿戴栏位、双武器组、格子背包、仓库、鉴定、符文之语、耐久、尸体回收及洗点。新职业操作、数值来源及适配差异见 [亚马逊与法师](docs/classes.md)，圣骑士规则见 [圣骑士角色系统](PALADIN.md)。

五幕现有 37 类普通怪物、27 种模型体型，所有守关首领均有独立招式配置；可躲避箭矢、毒液、范围法术和直线强招。装备数据保留 LoD 1.13 完整目录，当前可获取 434 个底材条目、364 条暗金、123 件套装、33 枚符文与 77 个符文之语，25 个首领均有特殊掉落配置。无功能杂物及未开放职业专属装备已关闭获取，清单见 [当前物品获取范围](docs/item-availability.md)。完整目录口径、概率来源和简化机制见 [装备目录与首领掉落](docs/item-catalog.md)；怪物说明见 [怪物与战利品扩充](EXPANSION.md)。

经验和战斗数值按三难度重新平衡，保留经典配点与技能协同，适度放宽耗蓝、续航和弹幕容错。包含精英的全清不重刷模拟等级约为普通 42、噩梦 70、地狱 91；现有角色不降级、不重置。具体数值与测试限制见 [平衡说明](docs/balance.md)，可运行 `npm run balance:report` 查看可复现的数值报告。

25 关采用独立长宽、每次进入重新生成的布局，最小 85 × 85，最大区域为 299 × 259，两个方向均不超过 300 格：阴湿墓园与哥特遗迹、砂岩古墓与星空浮桥、沼泽丛林与失落神殿、灰烬荒原与熔岩祭场、雪地城垒与世界之石。各关具有专属地标、连续地表材质和天气光照，详见 [五幕场景设计](docs/scenes.md)。每关有 4 至 6 个普通箱子，金币与药剂保底；另有普通 1～2、噩梦 3～4、地狱 5～6 只精英怪，装备与符文掉率分别为 55% 与 15%。地图、交互与掉落规则见 [地图与箱子](docs/maps-chests.md)，随机支路、探索迷雾、怪群分布和单关经验预算见 [随机远征与探索平衡](docs/random-maps.md)。

弓、弩、标枪、飞刀和飞斧使用实际飞行的远程攻击，默认无限弹药，无需购买箭矢或补充投掷数量；普通攻击和职业远程技能均适用，仍保留穿透、魔法箭和爆炸箭。装备维修只处理耐久。圣光弹、祝福之锤和天堂之拳次级弹统一检测飞行路径与墙体。操作、存档兼容和原作适配边界见 [远程武器与技能](docs/ranged-combat.md)。

暗金、套装和符文之语的可变属性已支持逐件随机：掉落生成或配方完成时掷值，鉴定、重载与导入保留原值。可变孔数遵循底材上限，图鉴继续显示稳定示例和合法范围；规则及存档兼容见 [装备随机变量](docs/item-rolls.md)。

三职业的角色模型、关节动作和战斗特效已重做，包括职业装束、武器轮廓、火焰、冰晶、闪电、毒雾和增益表现。预览与实现范围见 [角色与特效](docs/character-visuals.md)。

## 本地启动

Windows 双击 `start.cmd`，会自动打开浏览器。首次启动需要 Node.js 24.7+ 与网络连接以安装依赖。启动后可选择本地模式或在线模式；本地模式无需账号，在线模式使用随项目启动的账号与存档服务。

也可以在项目目录运行：

```powershell
npm ci
npm run dev
```

默认地址为 http://127.0.0.1:5173 ，端口被占用时启动报错，不再自动换端口，以免读到另一份本地存档。推荐使用开启硬件加速的现代 Edge / Chrome 浏览器，需要支持 WebGL 2。

开发与预览服务会识别访问者：选择本地模式后，服务电脑本机通过回环、局域网 IP 或其他主机名访问时，统一转往 `127.0.0.1`；其他电脑统一到服务电脑的首个可用 IPv4 地址，也可用 `D2R_LOCAL_ORIGIN` 指定供其他电脑使用的固定域名或地址。本机存档仍保存在本机浏览器，其他电脑不会因此共用角色。端口、路径与游戏参数保留，静态部署未运行本地入口接口时仅提供回环地址兼容。在线模式保留原访问地址与登录会话。

旧入口已有存档时先显示恢复页，不启动游戏或自动保存。点击“迁移角色并合并共享仓库”即可迁移到统一入口；统一入口的角色列表保留“找回 localhost 旧入口存档”链接。合并前在统一入口 IndexedDB 保存完整原始备份，旧入口原数据不删除。同一角色 ID 优先保留等级更高、战役通关更多的进度，再比较保存时间与版本；独立同名角色改名保留。共享装备按物品 ID 去重，角色已持有的装备不重复加入；共享仓库超出容量时放进“合并仓库余量”角色的个人仓库。相同 ID 的共享装备有不同属性时保留统一入口版本，其他版本保存在原始备份中。已合并的数据有凭据记录，重复迁移不会复活已取走的装备。写入中断保留恢复日志，下次打开统一入口继续完成；损坏数据或并发修改会明确报错。

角色导出仅包含个人仓库；恢复页还可下载包含共享仓库的完整原始备份。完整备份不能作为单角色文件导入。浏览器禁止网页枚举所有旧网站地址；需要从各个仍可访问的旧入口发起迁移，或使用已经导出的备份恢复。不同浏览器用户仍有各自独立的本地存档。

服务默认监听所有本机 IPv4 网卡，同一局域网内的电脑可以访问 `http://本机局域网IP:5173`，当前为 http://192.168.158.112:5173 。本机 IP 变化后需使用新地址，Windows 防火墙也需允许当前网络中的 Node.js 入站连接。本地模式下各电脑的角色存档独立；在线角色随账号保存在服务器，不是多人联机。

## 角色与存档

初始化时可选择**本地模式**或**在线模式**。在线模式支持注册登录、账号角色、JSON 存档上传与导出、账号共享仓库，以及 90 秒心跳超时自动退出；运行方式、断线后的进度规则和数据库备份见 [本地模式与在线模式](docs/online-mode-design.md)。两种模式的数据相互隔离。

本地模式同一浏览器入口的所有角色共用金币库存和符文仓库；在线模式同一账号的所有角色共用，账号之间互不影响。拾取、购买、鉴定、修理、镶嵌和符文合成均使用这份库存，切换或删除角色不会清空库存。旧角色的金币和未镶嵌符文会自动合并一次，原有存档保留；装备上的符文仍随装备保存。多窗口发生冲突时拒绝旧库存覆盖，并要求重新载入。

单角色导出包含当前共享金币与符文的快照；导入为新角色时，将文件中的金币和符文加入目标库存。共享装备仍不包含在单角色导出文件中。

每次打开或刷新页面，都会先选择游戏模式，再进入对应角色列表，不会自动进入战斗。列表显示角色名称、等级、难度、当前章节关卡、已通关数量与最近保存时间，并默认选中上次使用的角色。

角色选择页右上角的“百科”无需创建或载入角色即可使用。装备 / 物品图鉴收录当前全部底材、暗金、套装、符文之语、符文与补给，支持中英文搜索、分类、部位筛选、排序和分页；详情提供实际装备属性、符文镶嵌效果、可选底材的配方预览以及三难度首领来源。怪物图鉴包含 37 类普通怪物和 25 个首领，可按章节、类型与种族筛选，查看可旋转/缩放的动态模型、各出现地点和难度下的生命/伤害/抗性、战斗招式及特殊掉落。物品与首领详情可相互跳转，返回后保留查询状态；浏览不会改变角色存档。百科展示当前游戏已接入的属性和战斗规则。

- **新建角色**：选择圣骑士、亚马逊或法师，输入 1 至 16 个字符的名称，创建独立存档并进入游戏。本地角色在同一浏览器内、在线角色在同一账号内不能重名。亚马逊携带标枪和备用短弓；法师携带 +1 火弹短棍，鼠标右键默认施放火弹。角色的职业、装备、技能与关卡进度分别保存，旧角色仍为圣骑士。
- **继续旅程**：选择已有角色，再点击“进入旅程”，默认进入无怪物的罗格营地；新建角色和重新载入也从营地开始。每个角色的三个难度进度、任务、等级、属性、装备与背包分别保存。
- **营地与传送阵**：点击营地内的远征传送阵可自动走近并打开选关，也可靠近后按 F 或点击交互按钮。可选择已通关关卡与各已解锁难度的最新进度关卡，未解锁关卡不可进入。关卡中按 Esc，点击“返回营地”，成功保存后回到营地；再次进入当前未通关关卡保留任务进度，重玩已通关关卡会刷新怪物和首领。返回营地会清除该场景未拾取的掉落及战斗效果，遗体移回营地出生点。
- **切换角色**：暂停菜单中点击“保存并切换角色”。当前角色成功保存后才返回选择界面。
- **重命名与删除**：在角色列表中选中角色，使用下方的重命名或删除图标。删除需要再次确认，仅影响选中的角色。
- **单角色导出**：选中角色，点击下方下载图标，导出该角色的 JSON 存档，包含成长、装备、背包、仓库、符文和战役进度。游戏中先“保存并切换角色”，即可导出最新进度。
- **单角色导入**：点击角色列表右上方的上传图标，选择本游戏导出的 JSON 文件（最大 2 MB），预览后确认“导入为新角色”。可修改角色名称，同名时需改名；导入使用新的角色 ID，不覆盖任何已有角色，可用于跨电脑、浏览器或访问地址迁移。取消、文件损坏或写入失败不会修改已有存档。
- **旧存档迁移**：原有单角色存档会自动转换为“灰烬行者”，同时保留原始数据作为备份；迁移只执行一次，删除迁移后的角色不会将旧备份重新导入。
- **多窗口保护**：检测到其他窗口更新或删除当前角色时，当前游戏会暂停并提示重新选择，避免旧页面覆盖新的进度。不同角色可以在不同窗口独立保存。

创建或保存失败时会显示错误，不会以空白角色替换原有存档。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 鼠标模式：点击地面或按住左右键拖动寻路；WASD 模式：W/A/S/D 八方向移动；两种模式均可使用方向键 |
| 攻击 | 鼠标模式：点击敌人自动接近攻击，Shift + 左键原地攻击；WASD 模式：左键朝光标攻击，按住连放 |
| 副攻击 | 鼠标模式：右键单击施法，拖动或长按转为移动；WASD 模式：右键按下即施法，攻击技能可按住连放 |
| 四个快捷技能 | 鼠标模式：Q / W / E / R；WASD 模式：Q / E / R / 空格 |
| 技能树与技能配置 | T，或底栏技能图标 |
| 切换武器组 | X，或装备页切换图标 |
| 切换跑步 / 行走 | V，或耐力条旁图标 |
| 药水快捷键 | 1 / 2 / 3 / 4，在背包「共享药水」区域配置具体品种 |
| 给米山使用生命药剂 | 按住 Shift，再按 1 |
| 任务交互、拾取、补给、关卡出口 | F 或场景下方出现的交互按钮 |
| 背包 / 角色 / 任务 | I / C / J |
| 区域地图 | Tab / M |
| 暂停 / 切换移动方式 | Esc，在菜单的“移动方式”中选择鼠标或 WASD |
| 镜头缩放 | 鼠标滚轮 |

手机使用左侧摇杆移动、右侧攻击按钮和底部技能栏。打开面板或切换到其他窗口时会自动暂停。

默认使用鼠标移动，六个技能键为鼠标左右键和 Q/W/E/R。Esc 菜单可切换为 WASD 移动，四个快捷技能槽依次改用 Q/E/R/空格，鼠标左右键直接朝光标攻击或施法，点击敌人、地面及拖动均不会发起移动。WASD 斜向与直向等速，拾取、开箱、使用传送阵和仓库需先走近目标；冲锋、传送等位移技能仍可正常使用。模式保存在本机，刷新或切换角色后保留；切换模式会清除正在按住的输入与寻路，技能栏与配置页同步更新按键，原有技能选择不变。旧存档仍兼容，F1–F5 不作为技能别名。

普攻和各技能独立计时，释放后不会让其他技能进入公共冷却；同一技能仍受攻速、施法速度和自身冷却限制，重复绑定不能绕过限制。按住当前模式的快捷技能键可连续释放攻击技能，松键停止；光环、增益和召唤技能只触发一次。冷却结束前 0.18 秒内的点击或按键可缓冲一次，鼠标模式下移动、切换技能、暂停或失焦会取消待释放指令；WASD 移动期间仍可缓冲施法。普通攻击和施法最多锁定移动 0.12 秒，切换技能可结束尚未完成的连击；受击与格挡仍保留各自的恢复时间。

鼠标悬浮只更新瞄准位置，不会让角色转身；移动时角色朝行进方向，点击攻击或按技能键时才朝目标方向释放。冲锋、圣光弹和祝福之锤使用当前鼠标位置，热诚连击期间可随鼠标转向，天堂之拳选择鼠标所指的敌人。鼠标移动模式下，左键点怪可自动接近攻击，拖动后改为跟随移动；拖动松键、失去指针捕获或打开面板会停止跟随。开阔地面拖动实时跟随鼠标，绕障碍的路线平滑衔接，重算最高每秒 8 次；追击移动敌人最多每秒重算 5 次。普通点击移动或拖动期间施法保留路线，攻击或施法动作恢复后继续移动；冲锋、传送和取消交互会结束原路线。触屏技能保留自动选敌。

移动以实际建筑碰撞轮廓和角色半径判断通行，使用半格采样规划绕行，并按连续角度直行、提前衔接安全转弯；不再把小建筑周围额外整格封死。地图实体边界有对应的连续可见墙面，悬空地形仍以平台边缘为界。地面未鉴定装备只显示底材名称，带孔时额外显示 `[N孔]`，不会提前透露词缀或暗金、套装名称。

背包、私人仓库与共享仓库内可按住物品拖动，手机支持手指拖动。目标区域完整覆盖其中所有物品时，会交换两个区域：拖入物品占据目标位置，被覆盖的物品按原相对位置放回拖出区域。可交换时显示金色预览和交换件数；仅覆盖半件物品、交换后重叠、越界或拖到容器外时保持原位。拖动时按 Esc 取消，成功后立即保存。超长私人仓库靠近物品区上下边缘时自动滚动，面板标题与操作区保持固定。键盘可聚焦物品后按空格或 Enter 拿起，方向键移动，再按空格或 Enter 放下。跨容器转移仍使用详情中的存入或取出按钮。

可穿戴装备直接拖到对应装备部位即可穿戴，两枚戒指可分别指定左右栏位。可装备时部位显示绿色，不匹配、未鉴定或需求不足时显示红色并提示原因；替换装备放回来源容器。手机和较矮的横屏拖动时会临时显示装备栏，松手或取消后收起。

背包与仓库在桌面分为装备、物品、详情三个区域，常规容器尽量完整展示；小屏通过“物品 / 装备 / 详情”切换，点击物品自动显示详情。基础属性、全部词缀和镶嵌信息在同一页连续展示，不再切标签或翻页；宽屏并列显示词缀，长内容只在详情区内滚动，装备、鉴定和存取按钮固定在底部。符文之语每页四个配方，手机可切换材料与配方。角色属性及技能页在手机上也提供分区入口。

私人仓库与共享仓库均可直接穿戴物品、选择装备栏并卸下装备。换装时旧装备放回来源容器，双手武器会同时把主手和盾牌放回，背包已满也能在仓库换装。私人仓库页卸下的装备直接进入私人仓库；共享仓库页可选择卸下至共享或个人仓库。空间或装备需求不满足时，物品保持原位。

战斗左上方分别显示增益和减益，包含名称、图标、剩余时间与进度条；临近结束时边框变化，常驻灵气单独标明。中毒、冰冷与诅咒可同时显示，神圣之盾不会遮掉减益信息。鼠标悬浮或键盘聚焦可查看说明，提示框自动避开屏幕边缘。

界面统一使用黑铁与旧铜面板、暗红主操作、羊皮纸色文字和清晰的金色选中状态，保留暗黑 2 风格的红蓝资源球与装备品质颜色。面板标题包含功能图标和操作说明；Esc 菜单将旅程操作与游戏设置分区展示。角色选择页的导入、导出、改名和删除入口显示文字，空背包详情提供操作指引。首领血条与角色状态在手机上分别占位，避免互相遮挡。职业选择提供玩法说明与实时初始属性；面板支持方向键切换分类、空格操作及关闭后的焦点返回，暂停菜单附有操作手册。详见 [界面设计与操作](docs/ui-design.md)。

## 玩法

- 鼠标移动模式下，连续点击或拖动可在行走中更新路线；松开鼠标后继续前往最后指定的位置，暂停或取消输入时停止。
- 依次穿越坎杜拉斯、鲁高因、库拉斯特、群魔堡垒和哈洛加斯，每章五关。
- 每关完成一项简短击杀或交互任务，再击败守关首领。前四关击败小首领后开放下一关，第五关击败大首领后开放下一章。
- 五位章节首领依次为安达利尔、都瑞尔、墨菲斯托、迪亚波罗和巴尔。整套 25 关通关后才开放下一难度。
- 五档红蓝药水可掉落和购买，两种活力药剂仅低概率掉落；全部 15 种药水在背包共享药水区展示。本地全部角色／在线同账号全部角色共享药水库存，快捷键随角色保存，详见 [药水与共享库存](docs/potions.md)。
- 地面装备和护身符必须点击具体掉落物或标签后拾取，走过或使用范围拾取不会收入装备；远处点击会寻路到附近，仅拾取选中的物品。金币、药剂和符文保留自动拾取。移动、攻击或打开面板会取消尚未完成的点选拾取。
- 背包按物品尺寸占用 10 × 4 格；未鉴定装备在背包或仓库中直接花费 80 金币鉴定，不再购买或消耗卷轴。背包和仓库都可直接出售物品，仓库出售不需要背包空位。499 种实际底材使用各自的装备图案，同底材的名称别名共用图案；背包、装备栏和图鉴统一显示，并以材质饰边、品质标记、底色及边框区分稀有度。
- 完成第二章死亡之殿的“取回赫拉迪克方块”任务后，背包页永久增加 3 × 4 格方块空间，与普通背包同时显示，支持鼠标或触摸拖拽存取和完整物品交换。放入方块的护符不生效，取回普通背包后恢复；方块内容随角色保存和导出，已完成该关的旧角色自动解锁。
- 小怪装备、符文和护身符的独立掉率分别为 16%、3.5%、0.6%；小首领为 80%、28%、2.5%。章节首领保留两件基础装备、4% 魔法护符、首通暗金与符文保底，所有首领另有按身份配置的暗金和符文判定。女伯爵专用符文池普通/噩梦/地狱分别最高 Ral/Io/Ist，熔炉首通有额外符文；地狱迪亚波罗和巴尔各有 0.5% 特殊暗金护符。装备受怪物等级与 TC 限制，MF 不影响符文。
- 符文页收录从艾尔到萨德的 33 枚符文，提供无宝石升阶合成与“符文齐备”配方筛选；符文袋、镶嵌栏、配方和图鉴均显示 #1–#33 编号，图鉴支持按编号精确搜索符文及其配方。符文之语要求正确普通底材、武器类别、准确孔数和顺序；配方中的孔位次序与符文编号分别展示。
- 可镶嵌装备的详情列出匹配的符文之语，材料齐备的配方优先显示；悬浮或点击名称可查看属性。一键镶嵌按配方顺序消耗符文，支持补齐已有的正确前缀；缺料、错误顺序或不匹配的底材不会消耗材料。
- 每级获得 5 属性点与 1 技能点。技能树按等级与前置逐项解锁，每项最多投入 20 点。学习后在技能配置中分配主攻击、副攻击和四个快捷槽；未配置的快捷键和鼠标右键默认普通攻击，按住快捷键可连续攻击，按 T 打开技能配置。
- 灵气一次激活一种；可与战斗技能及神圣之盾同时使用。装备的技能加成不会增加协同技能的投入点数。
- 普通、魔法、稀有、套装、暗金和符文之语装备具有独立需求与词缀。装备涵盖主手、盾牌、头盔、铠甲、手套、靴子、腰带、项链和两枚戒指，另有一组备用主手与盾牌。
- 出生点附近的传送门提供免费状态恢复和药剂补给，方位随关卡朝向变化。
- 死亡后在出生点复活，穿戴装备留在遗体中；靠近遗体按 F 取回。金币损失比例随等级增加，最高 20%；噩梦与地狱还会损失本级经验，原地回收遗体返还已损失经验的 75%。
- 通关后不会弹出结算窗口，可自由收集掉落；靠近激活的传送门按 F 直接前往下一关，普通和噩梦最终关进入下一难度，地狱最终关返回营地。任务面板的关卡选择可重玩已通关关卡。已通关关卡重新进入时刷新首领，无需重做小任务；正常掉落保留，首次通关奖励不会重复领取。三个难度进度独立，噩梦与地狱分别有 -40% 与 -100% 抗性惩罚。
- 每个难度首次通关邪恶洞窟后，可在角色面板不限次数重置属性与技能，返还所有已投入的点数；已使用过洗点的旧存档同样适用。

## 存档与设置

营地新增 **本地共享仓库** 箱子，可从背包或个人仓库直接存入物品，也可直接取回这两个容器。同一浏览器、同一访问地址的本地角色共用 100 格空间，随机属性、孔数、镶嵌及数量保持不变；单角色导出不包含共享物品。使用方式与存取保护见 [共享仓库说明](docs/shared-stash.md)。

角色、装备、金币、属性与任务进度每 8 秒自动保存，重要操作后也会立即保存。页面右上角可手动保存。

本地模式的存档位于当前浏览器和访问地址的 `localStorage`，每个角色使用独立的 `eclipse-ii-profile-v2:<角色ID>` 键。`eclipse-ii-last-profile` 记录最近使用的角色；旧的 `eclipse-ii-save-v1` 仅作为迁移来源和备份保留。在线角色及账号共享仓库保存在服务端数据库中。

共享仓库及存取时的角色恢复快照使用本地 IndexedDB 事务保存，并保留 localStorage 兼容镜像。完整的本地状态包括这两类存储；清除网站数据会清除共享仓库。

旧守誓者转换为同级圣骑士，旧配点重新返还为该等级应有的属性点与技能点，装备、金币、任务和等级保留。旧多角色记录第一次保存为圣骑士时，会先原样备份到 `eclipse-ii-before-paladin:<角色ID>`；背包放不下的旧装备转入私人仓库。

旧墓园角色接入五幕战役时保留角色成长与物品，但新战役从普通第一关开始，旧墓园周目不解锁新难度。旧多角色记录首次保存新战役前备份到 `eclipse-ii-before-campaign:<角色ID>`。

重新加载并选定角色后默认进入营地，再经传送阵选择关卡；未拾取掉落和怪物会重置。未通关关卡保留当前小任务进度；已通关关卡会刷新首领，小任务保持完成。切换到尚未通关的关卡会重新开始该关任务。遗体会移回出生点，死亡代价不会因刷新或复活重复扣除；重新载入、返回营地或跨关后的遗体不返还经验。浏览器清除网站数据、换电脑、换浏览器、换端口或从 `127.0.0.1` 改为 `localhost` 都会使用不同的存档环境，角色不会通过局域网同步。

暂停菜单可调整音量、画质与全屏。低性能设备可切换“流畅”，关闭阴影和后处理。开始新的角色旅程不会替换其他角色，已通关角色可重玩关卡或进入已解锁的更高难度。

## 静态部署

```powershell
npm run build
npm run preview
```

构建后的 `dist` 可部署到静态 HTTP 服务器的网站根路径。请通过 HTTP 访问，不能直接双击 `index.html`。开发与预览服务默认支持局域网访问；如需仅供本机访问，可运行 `npm run dev -- --host 127.0.0.1`。
