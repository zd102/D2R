# 黯蚀 II · ECLIPSE

可在本地浏览器游玩的暗黑风格单人 ARPG，借鉴《暗黑破坏神 2》的等距视角、战斗与刷装备循环。五幕战役改编为五章、每章五关，包含普通、噩梦和地狱三个难度；不是原作引擎、地图及全部内容的复刻，没有使用暴雪原版素材。完整关卡、任务与推进规则见 [五幕战役](CAMPAIGN.md)。

角色系统已按经典《毁灭之王》圣骑士改造：四维属性、1 至 99 级、三系 30 技能、协同与灵气、十个穿戴栏位、双武器组、格子背包、仓库、鉴定、符文之语、耐久、尸体回收及洗点。规则来源、实现范围与适配差异见 [圣骑士角色系统](PALADIN.md)。

五幕现有 37 类普通怪物、27 种模型体型，所有守关首领均有独立招式配置；可躲避箭矢、毒液、范围法术和直线强招。装备扩充到 83 种底材、35 件暗金、6 件西刚套装、33 枚符文与 25 个符文之语。新增内容、掉率和改编差异见 [怪物与战利品扩充](EXPANSION.md)。

经验和战斗数值按三难度重新平衡，保留经典配点与技能协同，适度放宽耗蓝、续航和弹幕容错。全清不重刷的模拟等级约为普通 41、噩梦 67、地狱 89；现有角色不降级、不重置。具体数值与测试限制见 [平衡说明](docs/balance.md)，可运行 `npm run balance:report` 查看可复现的数值报告。

## 本地启动

Windows 双击 `start.cmd`，会自动打开浏览器。首次启动需要 Node.js 22.12+ 与网络连接以安装依赖；当前目录已安装依赖，之后运行游戏不需要外部网络，也没有账号或后端服务。

也可以在项目目录运行：

```powershell
npm ci
npm run dev
```

默认地址为 http://127.0.0.1:5173 ，端口被占用时 Vite 会使用下一个可用端口，以终端显示的地址为准。推荐使用开启硬件加速的现代 Edge / Chrome 浏览器，需要支持 WebGL 2。

服务默认监听所有本机 IPv4 网卡，同一局域网内的电脑可以访问 `http://本机局域网IP:5173`，当前为 http://192.168.158.112:5173 。本机 IP 变化后需使用新地址，Windows 防火墙也需允许当前网络中的 Node.js 入站连接。各电脑的角色存档独立，不是多人联机。

## 角色与存档

每次打开或刷新页面，都会先进入角色选择界面，不会自动进入战斗。列表显示角色名称、等级、难度、当前章节关卡、已通关数量与最近保存时间，并默认选中上次使用的角色。

- **新建角色**：输入 1 至 16 个字符的名称，创建独立存档并进入游戏。同一浏览器内的角色名称不能重复。目前所有角色均使用圣骑士职业，一级从普通攻击开始。
- **继续旅程**：选择已有角色，再点击“进入旅程”；点击“关卡选择”可重玩已通关关卡或返回推进关卡。每个角色的三个难度进度、任务、等级、属性、装备与背包分别保存。
- **切换角色**：暂停菜单中点击“保存并切换角色”。当前角色成功保存后才返回选择界面。
- **重命名与删除**：在角色列表中选中角色，使用下方的重命名或删除图标。删除需要再次确认，仅影响选中的角色。
- **旧存档迁移**：原有单角色存档会自动转换为“灰烬行者”，同时保留原始数据作为备份；迁移只执行一次，删除迁移后的角色不会将旧备份重新导入。
- **多窗口保护**：检测到其他窗口更新或删除当前角色时，当前游戏会暂停并提示重新选择，避免旧页面覆盖新的进度。不同角色可以在不同窗口独立保存。

创建或保存失败时会显示错误，不会以空白角色替换原有存档。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，或点击地面自动寻路 |
| 攻击 | 点击敌人后自动接近并攻击；Shift + 鼠标左键原地攻击 |
| 副攻击 | 鼠标右键，使用已配置的技能或灵气 |
| 三个快捷技能 | Q / E / R，空格与 R 共用绑定 |
| 技能树与技能配置 | T，或底栏技能图标 |
| 切换武器组 | X，或装备页切换图标 |
| 切换跑步 / 行走 | V，或耐力条旁图标 |
| 生命 / 法力药剂 | 1 / 2 |
| 任务交互、拾取、补给、关卡出口 | F 或场景下方出现的交互按钮 |
| 背包 / 角色 / 任务 | I / C / J |
| 区域地图 | Tab / M |
| 暂停 | Esc |
| 镜头缩放 | 鼠标滚轮 |

手机使用左侧摇杆移动、右侧攻击按钮和底部技能栏。打开面板或切换到其他窗口时会自动暂停。

背包与仓库内可按住装备拖动到空格，手机支持手指拖动。落点显示绿色或红色的占格预览，重叠、越界或拖到容器外不会移动装备；拖动时按 Esc 取消。仓库靠近面板上下边缘时自动滚动，成功移动后立即保存位置。键盘可聚焦装备后按空格或 Enter 拿起，方向键移动，再按空格或 Enter 放下。跨容器转移仍使用装备详情中的存入或取出按钮。

## 玩法

- 依次穿越坎杜拉斯、鲁高因、库拉斯特、群魔堡垒和哈洛加斯，每章五关。
- 每关完成一项简短击杀或交互任务，再击败守关首领。前四关击败小首领后开放下一关，第五关击败大首领后开放下一章。
- 五位章节首领依次为安达利尔、都瑞尔、墨菲斯托、迪亚波罗和巴尔。整套 25 关通关后才开放下一难度。
- 地面装备和护身符必须点击具体掉落物或标签后拾取，走过或使用范围拾取不会收入装备；远处点击会寻路到附近，仅拾取选中的物品。金币、药剂和符文保留自动拾取。移动、攻击或打开面板会取消尚未完成的点选拾取。
- 背包按物品尺寸占用 10 × 4 格；未鉴定装备在背包或仓库中直接花费 80 金币鉴定，不再购买或消耗卷轴。背包和仓库都可直接出售物品，仓库出售不需要背包空位。护身符使用符纸图标，项链使用宝石图标。
- 小怪装备、符文和护身符的独立掉率分别为 16%、3.5%、0.6%；小首领为 80%、28%、2.5%。章节首领固定掉两件装备，护身符掉率 4%，首通保底一件暗金和一枚符文，重刷不再固定暗金；女伯爵固定掉 2–3 枚符文。装备与符文档次取决于区域和难度，不再跟随玩家等级。
- 符文页收录从艾尔到萨德的 33 枚符文，提供无宝石升阶合成与“符文齐备”配方筛选；符文之语要求正确普通底材、武器类别、准确孔数和顺序。
- 每级获得 5 属性点与 1 技能点。技能树按等级与前置逐项解锁，每项最多投入 20 点。学习后在技能配置中分配主攻击、副攻击和三个快捷槽。
- 灵气一次激活一种；可与战斗技能及神圣之盾同时使用。装备的技能加成不会增加协同技能的投入点数。
- 普通、魔法、稀有、套装、暗金和符文之语装备具有独立需求与词缀。装备涵盖主手、盾牌、头盔、铠甲、手套、靴子、腰带、项链和两枚戒指，另有一组备用主手与盾牌。
- 出生点西侧的传送门提供免费状态恢复和药剂补给。
- 死亡后在出生点复活，穿戴装备留在遗体中；靠近遗体按 F 取回。金币损失比例随等级增加，最高 20%；噩梦与地狱还会损失本级经验，原地回收遗体返还已损失经验的 75%。
- 通关后可以先收集掉落，再从结算页继续下一关或“再刷本关”；角色选择页和暂停菜单均可选关重玩。已通关关卡重新进入时刷新首领，无需重做小任务；正常掉落保留，首次通关奖励不会重复领取。结算页重刷会在还有未拾取战利品时要求确认。三个难度进度独立，噩梦与地狱分别有 -40% 与 -100% 抗性惩罚。
- 每个难度首次通关邪恶洞窟后获得一次重置属性与技能的机会，在角色面板确认使用。

## 存档与设置

角色、装备、金币、属性与任务进度每 8 秒自动保存，重要操作后也会立即保存。页面右上角可手动保存。

存档位于当前浏览器和访问地址的 `localStorage`，每个角色使用独立的 `eclipse-ii-profile-v2:<角色ID>` 键。`eclipse-ii-last-profile` 记录最近使用的角色；旧的 `eclipse-ii-save-v1` 仅作为迁移来源和备份保留。

旧守誓者转换为同级圣骑士，旧配点重新返还为该等级应有的属性点与技能点，装备、金币、任务和等级保留。旧多角色记录第一次保存为圣骑士时，会先原样备份到 `eclipse-ii-before-paladin:<角色ID>`；背包放不下的旧装备转入私人仓库。

旧墓园角色接入五幕战役时保留角色成长与物品，但新战役从普通第一关开始，旧墓园周目不解锁新难度。旧多角色记录首次保存新战役前备份到 `eclipse-ii-before-campaign:<角色ID>`。

重新加载并选定角色后会从当前关卡传送阵继续，未拾取掉落和怪物会重置。未通关关卡保留当前小任务进度；已通关关卡会刷新首领，小任务保持完成。切换到尚未通关的关卡会重新开始该关任务。遗体会移回传送阵，死亡代价不会因刷新或复活重复扣除；重新载入或跨关后的遗体不返还经验。浏览器清除网站数据、换电脑、换浏览器、换端口或从 `127.0.0.1` 改为 `localhost` 都会使用不同的存档环境，角色不会通过局域网同步。

暂停菜单可调整音量、画质与全屏。低性能设备可切换“流畅”，关闭阴影和后处理。开始新的角色旅程不会替换其他角色，已通关角色可重玩关卡或进入已解锁的更高难度。

## 静态部署

```powershell
npm run build
npm run preview
```

构建后的 `dist` 可部署到静态 HTTP 服务器的网站根路径。请通过 HTTP 访问，不能直接双击 `index.html`。开发与预览服务默认支持局域网访问；如需仅供本机访问，可运行 `npm run dev -- --host 127.0.0.1`。

## 验证与项目结构

```powershell
npm test
npm run build
npm run test:browser
```

浏览器测试默认使用 Windows 已安装的 Microsoft Edge，需先保持开发服务器运行。可用 `BASE_URL` 环境变量指定其他地址。测试使用独立的临时浏览器环境，不修改日常浏览器存档，截图输出到 `.verification`。

- `src/game.ts`：战斗、掉落、成长、输入与存档流程。
- `src/world.ts`：原创程序化模型与纹理、Cannon ES 碰撞、PathFinding.js A* 寻路。
- `src/bestiary.ts`、`src/monster-models.ts`、`src/monster-combat.ts`：分章怪物与首领表、独立模型、攻击预警、投射物、范围攻击和限量召唤。
- `src/item-expansion.ts`、`src/loot.ts`：装备与符文扩充、区域掉落权重、首通和女伯爵奖励、符文升阶。
- `src/affixes.ts`、`src/affix-data.ts`、`src/item-description.ts`：原始蓝黄词缀数据、三尺寸护身符、属性变量与详情显示；来源及适配边界见 [词缀说明](docs/affixes.md)。
- `src/campaign.ts`：五章 25 关、任务与首领数据、难度曲线、关卡解锁及布局。
- `src/campaign-ui.ts`、`src/campaign.css`：关卡选择、任务详情与通关结算。
- `src/ui.ts`、`src/style.css`：中文界面与触屏适配。
- `src/model.ts`：角色数据、装备与存档校验。
- `src/paladin.ts`：圣骑士 30 技能定义、协同、数值与经验表。
- `src/balance.ts`：怪物经验、等级差与高等级经验折减、各类怪物和首领实战属性。
- `src/items.ts`：底材、词缀、暗金与套装、符文之语、背包布局。
- `src/combat.ts`：逐击战斗、法术轨迹、灵气、控制效果与伤害结算。
- `src/character-ui.ts`、`src/character.css`：角色、技能树及装备界面。
- `src/inventory-drag.ts`：背包与仓库的鼠标、触摸和键盘拖动交互。
- `src/saves.ts`：角色存档管理、旧存档迁移与冲突检测。
- `src/profiles-ui.ts`、`src/profiles.css`：角色选择、新建、重命名与删除界面。
- `src/audio.ts`：本地合成音效。

渲染使用 [Three.js](https://threejs.org/docs/)，碰撞使用 [Cannon ES](https://github.com/pmndrs/cannon-es)，界面图标使用 Lucide。场景、角色、纹理和音效均随代码本地生成，不依赖 CDN、外部图片或远程 API。
