# 黯蚀 II · ECLIPSE

可在本地浏览器游玩的原创暗黑风格单人 ARPG，借鉴《暗黑破坏神 2》的等距视角、战斗与刷装备循环。这是一个完整可通关的小型游戏，并非原作全部章节、职业及内容的复刻；没有使用暴雪原版素材。

## 本地启动

Windows 双击 `start.cmd`，会自动打开浏览器。首次启动需要 Node.js 22.12+ 与网络连接以安装依赖；当前目录已安装依赖，之后运行游戏不需要外部网络，也没有账号或后端服务。

也可以在项目目录运行：

```powershell
npm ci
npm run dev
```

默认地址为 http://127.0.0.1:5173 ，端口被占用时 Vite 会使用下一个可用端口，以终端显示的地址为准。推荐使用开启硬件加速的现代 Edge / Chrome 浏览器，需要支持 WebGL 2。

服务默认监听所有本机 IPv4 网卡，同一局域网内的电脑可以访问 `http://本机局域网IP:5173`，当前为 http://192.168.158.112:5173 。本机 IP 变化后需使用新地址，Windows 防火墙也需允许当前网络中的 Node.js 入站连接。各电脑的角色存档独立，不是多人联机。

## 角色与存档

每次打开或刷新页面，都会先进入角色选择界面，不会自动进入战斗。列表显示角色名称、等级、周目、任务进度与最近保存时间，并默认选中上次使用的角色。

- **新建角色**：输入 1 至 16 个字符的名称，创建独立存档并进入游戏。同一浏览器内的角色名称不能重复。目前所有角色均使用守誓者职业。
- **继续旅程**：选择已有角色，再点击“进入旅程”。每个角色的等级、属性、装备、背包、金币、药剂及祭坛任务分别保存。
- **切换角色**：暂停菜单中点击“保存并切换角色”。当前角色成功保存后才返回选择界面。
- **重命名与删除**：在角色列表中选中角色，使用下方的重命名或删除图标。删除需要再次确认，仅影响选中的角色。
- **旧存档迁移**：原有单角色存档会自动转换为“灰烬行者”，同时保留原始数据作为备份；迁移只执行一次，删除迁移后的角色不会将旧备份重新导入。
- **多窗口保护**：检测到其他窗口更新或删除当前角色时，当前游戏会暂停并提示重新选择，避免旧页面覆盖新的进度。不同角色可以在不同窗口独立保存。

创建或保存失败时会显示错误，不会以空白角色替换原有存档。

## 玩法

- 探索遗忘墓园，击败复生骸骨与堕落守卫。
- 清除每座祭坛附近的守卫，净化西庭、东庭和圣所三座祭坛。
- 三座祭坛净化后，前往北部圣所击败无光者·莫德雷克，获得传奇装备。
- 靠近掉落物会自动拾取，较远的装备标签可以点击寻路拾取。背包中选择装备后可装备或分解为金币。
- 升级获得 3 点属性，可以分配力量、体魄和灵性。装备分为普通、魔法、稀有、传奇四档，有武器、护甲、戒指三个槽位。
- 出生点西侧的传送门提供免费状态恢复和药剂补给。
- 死亡后可在出生点复活，损失 10% 金币。通关后可以继续收集掉落，并在暂停菜单进入下一周目；保留角色与装备，敌人会增强。

## 存档与设置

角色、装备、金币、属性与任务进度每 8 秒自动保存，重要操作后也会立即保存。页面右上角可手动保存。

存档位于当前浏览器和访问地址的 `localStorage`，每个角色使用独立的 `eclipse-ii-profile-v2:<角色ID>` 键。`eclipse-ii-last-profile` 记录最近使用的角色；旧的 `eclipse-ii-save-v1` 仅作为迁移来源和备份保留。

重新加载并选定角色后会从传送阵继续，未拾取的掉落和当前怪物状态会重置。死亡时刷新同样会扣除金币并复活。浏览器清除网站数据、换电脑、换浏览器、换端口或从 `127.0.0.1` 改为 `localhost` 都会使用不同的存档环境，角色不会通过局域网同步。

暂停菜单可调整音量、画质与全屏。低性能设备可切换“流畅”，关闭阴影和后处理。开始新的角色旅程不会替换其他角色，已通关角色仍可进入下一周目。

## 静态部署

```powershell
npm run build
npm run preview
```

构建后的 `dist` 可部署到静态 HTTP 服务器的网站根路径。请通过 HTTP 访问，不能直接双击 `index.html`。开发与预览服务默认支持局域网访问；如需仅供本机访问，可运行 `npm run dev -- --host 127.0.0.1`。

## 验证与项目结构

```powershell
npm test
npm run build
npm run test:browser
```

浏览器测试默认使用 Windows 已安装的 Microsoft Edge，需先保持开发服务器运行。可用 `BASE_URL` 环境变量指定其他地址。测试使用独立的临时浏览器环境，不修改日常浏览器存档，截图输出到 `.verification`。

- `src/game.ts`：战斗、掉落、成长、输入与存档流程。
- `src/world.ts`：原创程序化模型与纹理、Cannon ES 碰撞、PathFinding.js A* 寻路。
- `src/ui.ts`、`src/style.css`：中文界面与触屏适配。
- `src/model.ts`：角色数据、装备与存档校验。
- `src/saves.ts`：角色存档管理、旧存档迁移与冲突检测。
- `src/profiles-ui.ts`、`src/profiles.css`：角色选择、新建、重命名与删除界面。
- `src/audio.ts`：本地合成音效。

渲染使用 [Three.js](https://threejs.org/docs/)，碰撞使用 [Cannon ES](https://github.com/pmndrs/cannon-es)，界面图标使用 Lucide。场景、角色、纹理和音效均随代码本地生成，不依赖 CDN、外部图片或远程 API。
