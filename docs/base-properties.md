# 底材原生属性、超强与无形

新增掉落按 D2R 数据生成；旧存档不补掷、不重掷。范围为现有底材与已开放职业，不增加术士或新底材目录。底材原生属性、超强及无形不需要鉴定；蓝黄装备未鉴定时也显示这些属性，额外魔法词缀仍需鉴定。地面标签显示超强名称、`[无形]`、`[N孔]`，普通无形/带孔物品使用灰色标签，无形装备图案半透明。

## 数据与概率

导入器 [import-base-properties.mjs](../scripts/import-base-properties.mjs) 固定使用 [D2R 数据 fc46999](https://github.com/blizzhackers/d2data/tree/fc469993502d0498809b9fc1af140ee2a9eb8902/json) 的 Weapons、Armor、ItemTypes、AutoMagic、QualityItems、ItemRatio、Skills。运行时不访问网络。

- **自动词条**：读取底材 auto prefix 组，按 ilvl、qlvl、magic level 计算 alvl，过滤等级和稀有品质限制后按 frequency 抽取。具有 magic level 的底材使用 frequency × 词条等级权重。圣骑士盾抽全抗或伤害/准确率组合；法球抽生命或法力；亚马逊专属武器抽对应技能系。词条独立于蓝黄前后缀。非魔法底材不因自动词条提高需求等级。
- **单项技能**：候选技能来自 ItemTypes.StaffMods 与 Skills。0–99 整数判定，目标条数 0/1/2/3 的概率为 31%/40%/20%/9%。基础技能档位按 ilvl 1–11、12–18、19–24、25–36、37+ 划分，再以 19%/50%/20%/11% 选择 +1/0/−1/−2 档。每档五个技能，重复或不适用于底材的技能最多重试六次；失败不产生非法技能。每条 +1/+2/+3 概率为 60%/30%/10%。劣质物品限制档位与 +1 技能。圣盾、盾击不能作为权杖原生技能。
- **超强**：高品质判定失败后执行 `1 / max(1, HiQuality − trunc((ilvl − qlvl) / HiQualityDivisor))`。普通类型参数为 12/8，职业专属为 9/8；MF 不直接影响超强判定。超强失败后继续 Normal 判定，失败成为劣质，不能把这部分概率全部转成普通。
- **超强属性**：从适用的 QualityItems 行等概率选一组，再分别在整数区间内掷值。防具为 5–15% 增强防御、10–15% 耐久或两者；武器为增强伤害、准确率、耐久中的一项或两项。无耐久、投掷类排除耐久组。低伤武器的增强伤害不足一点时用 +1 最大伤害。
- **无形**：符合条件的武器、防具独立 5%；排除劣质、套装、任务物品、无耐久底材及原生无法破坏物品，保留暗金强制无形属性。武器基础伤害或防具基础防御 ×1.5 后向下取整，力量/敏捷需求减 10、最低 0；耐久按原版整数顺序减半并 +1，耐久词条另按顺序叠加。
- **孔数**：普通/超强可镶嵌装备自然带孔判定为 33%，孔数在 1 至上限间均匀抽取。上限同时受底材、ilvl 25/40 分档和普通/噩梦/地狱 3/4/6 孔限制。劣质和投掷物不自然带孔。

算法参考 [物品生成代码](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/ITEMS/Items.cpp)、[词条与超强组合](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/ITEMS/ItemsMagic.cpp)；D2R 数据字段见 [Data Guide](https://locbones.github.io/D2R_DataGuide/)。D2R 排除非法技能重试后的旧版泄漏行为。属性及整数取整例子见 [Arreat Summit](https://classic.battle.net/diablo2exp/items/basics.shtml)。

## 获取与保留

怪物常规装备现在使用 ItemRatio 品质判定，暗金/套装必须匹配已选底材，失败分别降为三倍耐久黄装/双倍耐久蓝装。箱子及首领专属装备也接入原生属性/无形生成。牛关额外底材按强制带孔路径生成；项目专有底材商人的原生属性由货单 ID 固定，无形不进入商人货单。

项目的怪物/箱子数量、底材选择池、首领首通保底和专属奖励仍使用现有战利品设计，**不等于重制版完整怪物 TreasureClassEx 掉落率**。这里的精确概率指选定底材后的品质、原生词条、超强/无形与自然孔判定；项目额外奖励明确属于强制路径。

无形不能通过城镇维修恢复耐久或聚气；已有自动修复、无法破坏和雇佣兵不耗耐久机制继续适用。符文之语累加到底材原属性，保存原生词条及无形/超强标记。带增强防御的防具使用最大基础防御 +1，无形倍率只执行一次，不实现旧版重复无形防御漏洞。钝器家族固定 +50% 对不死生物伤害独立结算。

验证覆盖概率边界与统计采样、职业词条、无形排除、整数取整、维修、符文之语、存档，以及桌面/手机未鉴定属性展示。
