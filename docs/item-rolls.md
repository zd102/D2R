# 暗金、套装与符文之语随机变量

更新日期：2026-09-11。适用于本地项目已接入的 LoD 1.13 装备目录：379 条暗金、127 件套装和 84 个符文之语。

## 玩家行为

暗金、套装的属性在物品生成时随机，普通怪物、首领、箱子与特殊暗金护符均使用同一生成流程。符文之语在最后一枚正确符文镶入、配方成立时随机。相同装备可以有不同变量；固定属性保持固定，不增加额外词缀。

每条原始可变属性在闭区间内等概率选取合法整数，包括最小值和最大值。不同属性独立掷值；同一条“所有属性”生成的一组力量、敏捷、体力、精力共享该条结果。换算成百分比、每级数值等内部单位时，保留已有原表转换规则。

| 示例 | 现在实际可生成的变量 |
| --- | --- |
| 蛇魔法师之皮 | 所有抗性 20–35；魔法伤害减少 9–13；施法速度固定 30% |
| 塔拉夏腰带 | MF 10–15 |
| 精神 | 施法速度 25–35%；法力 89–112 |
| 彩虹刻面 | 相应元素技能增伤和减抗分别在 3–5 内随机 |
| 盗墓者 | 孔数 1–3，其他已支持的变量分别随机 |

原表 `sock` 的可变孔数也在生成时随机，受底材最大孔数限制。原表区间超过底材容量时，先收窄为合法区间再掷值，例如艾尔多武器的原始 2–5 在该底材上只生成 2–3 孔。固定孔数仍固定。

“增加 5–30 火焰伤害”这类属性的两个数表示每次攻击的伤害上下界，不会错误地压成一个生成时随机常数。触发法术中的概率和技能等级也不当作同一变量区间。其他职业技能及未实现的装备效果继续按原有方式标注；这次不新增这些效果的战斗实现。套装件数奖励继续使用现有条件计算；当前已生效的组合奖励没有需要逐件随机的数值，尚未接入的 `add func=1` 条件仍未实现。

## 保存与展示

- 鉴定只揭示已生成属性，不重新掷值。查看详情、穿脱、切换武器、访问仓库、暂停、重载以及角色导出/导入均保留原值。
- 新生成物品记录 `catalogVersion: 2` 和逐条随机记录 `catalogRolls`，实际战斗继续读取保存的 `mods`。随机记录用于还原配方本身的属性贡献，避免符文之语的变量区间随着本次掷值漂移。
- 符文附加值和底材已有属性只叠加一次。比如精神无论生成 25% 还是 35% 施法速度，详情中的合法范围始终为 25–35%。
- 刻面镶嵌时连同实际属性和随机记录转入孔中；读取宿主装备时不会把刻面的 3/5 等结果统一改回 4/4。
- 已有 `catalogVersion: 1` 装备保留原数值和孔数，不自动变成一批新随机装备。旧版远程属性兼容只补缺失项，不覆盖现有项。更早、没有目录版本的历史装备仍执行原有目录修复流程，不在读取时随机。
- 图鉴使用稳定的中间档示例并显示合法范围；重复打开不会变化，预览也不消耗游戏属性随机流。蓝黄装备继续使用原有独立词缀系统。

## 实现与验证

主要代码为 [item-catalog.ts](../src/item-catalog.ts) 的 `rollCatalogMods`、`catalogItemMods` 与 `catalogModifierRanges`，[items.ts](../src/items.ts) 的 `specialItem`、`socketItem` 和迁移流程，以及 [model.ts](../src/model.ts) 的保存解析与刻面镶嵌。

`tests/item-rolls.test.ts` 覆盖全部 506 件特殊装备的两端取值和存档，全部 84 个符文之语及允许部位的配方/符文附加值，8,000 次蛇皮抽样分布，可变孔数、伤害范围语义、掉落随机源传递、刻面、旧档和导入导出。

`npm run test:item-rolls` 在桌面与手机视口验证鉴定、真实界面镶嵌完成精神、实际属性与范围显示、重载、图鉴切换底材和稳定预览。可设置 `BASE_URL` 指向运行中的服务，`OUTPUT_DIR` 指定截图目录。全量回归使用 `npm test`，类型检查使用 `npx tsc --noEmit`，生产构建使用 `npm run build`。
