# 七职业与重制版职业机制

项目可创建圣骑士、亚马逊、法师、死灵法师、野蛮人、德鲁伊和刺客。每个职业三系、30 个可学习技能，合计 210 个。职业创建、属性成长、单项技能加成、技能系护身符、专属装备、鼠标与快捷键、洗点以及本地／在线存档共用同一套规则。

## 规则基准

新增四职业的技能编号、等级、前置、伤害分段、耗蓝和原始协同由 `scripts/import-expansion-skills.mjs` 从固定版本 [LoD 1.13 数据](https://github.com/fabd/diablo2/tree/e67aa992be5db412bd0437bb8afb95eedee0c9bc/code/d2_113_data) 导入。脚本同时导入双手剑的单手伤害与靴子踢击伤害，生成表与运行时调整分离。

采用重制版 [2.4](https://news.blizzard.com/en-gb/article/23788293/diablo-ii-resurrected-patch-2-4-ladder-now-live)、[2.4.3](https://news.blizzard.com/en-gb/article/23814050/diablo-ii-resurrected-patch-2-4-3-now-live)、[2.6](https://news.blizzard.com/en-gb/article/23899624/diablo-ii-resurrected-ladder-season-three-has-concluded) 和 [2.7](https://news.blizzard.com/en-gb/article/23938388/diablo-ii-resurrected-ladder-season-4-has-concluded) 的职业特点和精选调整。原有三职业及短战役规则继续适用，见 [已有职业规则](classes.md) 和 [精选平衡调整](modern-balance.md)。

## 职业玩法

| 职业 | 技能系 | 已接入的核心机制 |
| --- | --- | --- |
| 死灵法师 | 诅咒、毒素与白骨、召唤法术 | 骷髅战士与元素法师、四种互斥石魔、重生、尸爆、毒云、贯穿骨矛、追踪骨魂、白骨装甲、可被击碎的骨墙和骨牢 |
| 野蛮人 | 战斗技能、战斗专家、战嗥 | 双持与双投、逐手伤害和命中、移动旋风、跳跃及落地伤害、狂乱叠加、武器专精、友军战嗥、尸体搜索 |
| 德鲁伊 | 召唤、变形、元素 | 狼人／熊人外形与动作、形态技能限制、狂怒与撞槌、毒素传染、物理／火焰混合伤害、冰冷风暴、狼群与灰熊同时存在、灵和藤蔓 |
| 刺客 | 陷阱、影子训练、武学技艺 | 五个守卫共享上限、自动索敌与射击次数、亡者守卫尸爆、双爪格挡、六种独立聚气、逐层终结、靴子踢击、影子战士与大师 |

打开技能页配置鼠标左右键和 QWER。HUD 显示召唤总数、陷阱数量、武学聚气层数与变形装备印记，召唤数量提示可查看各召唤物生命。双持角色可把合适的武器拖到副手栏；野蛮人可单手使用双手剑。备用武器组与死亡遗体继续使用原有存储结构。

普通攻击也能释放刺客聚气。速度爆发与消退互斥。德鲁伊的灵狼、狂狼和灰熊可共存，三种灵互斥、三种藤蔓互斥；变形状态可刷新飓风装甲、暴风与毁天灭地。死灵法师的四种石魔互斥；骷髅和重生需要可用尸体。吸引不会被后续诅咒覆盖，迷乱改变怪物目标选择。

## 装备和持久化

- 恢复原先关闭的 66 种专属底材、19 件暗金／套装及 Chaos 配方。全部七职业、21 个技能系的词缀、护身符和原生技能词条参与生成与结算。
- 新增马赛克、变形及武器版躁动。马赛克的两把爪可合计 100% 不消耗聚气并刷新持续时间；变形通过狼／熊命中获得各自的 180 秒印记；躁动武器可触发速度爆发。
- 两手武器的局部增强伤害、元素伤害、攻速、吸取与命中效果分别结算；职业技能、属性和装备灵气仍可共同生效。
- 钢铁石魔消耗地面装备，保留装备副本并结算伤害、元素附伤、抗性、吸血、压碎性打击、击中触发及装备灵气。物品副本加入服务端重复物品检查。
- 新职业召唤物跨区与重载保留种类、施放等级、生命比例和剩余时间；钢铁石魔保留其装备。该持久化范围是本项目的便利适配。投射物、陷阱、骨墙和武学聚气不写入存档。死亡及洗点清除召唤与临时战斗对象。
- 原有角色的职业、物品 ID、属性随机记录和存档格式保留。服务端创建、保存与导出都支持新职业；历史存档不要求新增可选字段。

## 适配边界

这是现有实时 3D 游戏中的职业还原，不是原版引擎逐帧复制。动作速度、地图距离、范围、召唤物生命和伤害仍有本地适配；狼、熊、石魔及人物为程序模型。召唤物不会获得完整原作隐藏装备，骷髅法师采用简化元素成长，重生主要保留怪物外形、生命、抗性及近战／远程特征，影子 AI 使用选定技能组合。召唤寻路、数量和弹体均有上限。

寻找物品复用现有怪物掉落池，不增加经验或击杀数；尸体只能消耗一次。尸爆排除人数倍率增加的尸体生命，分别结算物理与火焰抗性。普通怪物尸体的碎裂、完整原作尸体类型规则、全部攻击帧表和所有召唤隐藏属性尚未逐项对齐。现有无限投掷弹药规则继续适用。

## 验证

`tests/expansion-classes.test.ts` 覆盖全部新增主动技能的实际效果、七职业成长、双持、装备与词缀、尸体、诅咒、召唤、变形、陷阱、聚气和存档。服务端回归覆盖四职业的认证创建、保存及读取。`npm run test:expansion-classes` 检查十二棵技能树、键盘施法、真实战斗对象、跨区、重载和 360／390 像素布局；`BASE_URL` 和 `OUTPUT_DIR` 可覆盖现有服务与输出目录。
