# 当前物品获取范围

本次检查覆盖普通怪、精英、25 个首领及首通奖励、普通箱子、商店、新角色赠送、符文升级与镶嵌制作。以当前经典七职业可使用的功能为准；只有收藏或出售价值、没有装备、使用或制作用途的物品退出获取池。

## 已关闭的获取路径

| 物品 | 数量 | 原因与处理 |
| --- | ---: | --- |
| 宝石及骷髅 | 28 | 七类各四个等级，未实现宝石镶嵌或合成；关闭箱子掉落 |

| 城镇传送与辨视卷轴 | 2 | 回城走营地入口，鉴定直接付金币；关闭箱子掉落，新角色不再赠送鉴定卷轴 |

| 无属性白色戒指、项链、珠宝 | 3 类品质结果 | 没有基础战斗属性或白装合成用途；与箱子规则统一，新生成的这三类物品最低为有词缀的魔法品质 |

39 种杂物在原始箱子宝藏表中抽中后视为空抽，不重抽或替换成装备、符文。箱子的金币和生命/法力药剂保底继续生效。装备池在同一等级、宝藏等级与品质范围内筛选可用装备。

可获取目录现有 500 个底材条目、379 件暗金、127 件套装、87 个符文之语和全部 33 枚符文。百科、相关物品链接、首领来源及背包配方列表使用相同的可用范围，原有底材 ID 保持稳定。

新增四职业后恢复 66 种专属底材、19 件暗金／套装与 Chaos 配方；马赛克、变形和武器版躁动同时接入，见 [职业机制](restored-classes.md)。

## 保留规则

七种已开放职业的专属装备均保留，可通过共享仓库交给对应职业。普通武器、防具及有孔底材仍有装备或符文之语用途；低等级装备、仅部分属性生效的通用装备、仍有单件收益的套装部件也保留。所有可用暗金/套装均有已实现属性，符文、珠宝与护身符具有实际镶嵌或战斗用途。

原始导入数据和完整物品定义保留，用于来源核对、旧存档解析与旧物品展示；运行时统一过滤，重新导入数据不会恢复已关闭的获取路径。已有杂物和专属装备仍可保存、存取与出售，已有鉴定卷轴和弹药储备数量也保持原值；读取缺失的卷轴或储备字段时默认为零。

## 验证

`tests/item-availability.test.ts` 定向选择全部 39 种杂物的原始箱子分支，确认仅剩保底补给；检查三难度、25 关的怪物及首领掉落、无属性首饰、禁用配方的原子性、百科来源和新角色赠送。现有箱子、符文、装备变量与存档测试继续覆盖可用物品的概率、制作和兼容性。
