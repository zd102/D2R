# 职业与过渡装备调整

2026-09-11。按前三批建议实现战斗和装备改进；本次不包含掉落过滤、收藏记录、佣兵、方块配方或恐怖地带。

## 规则来源与范围

采用重制版 [2.4](https://news.blizzard.com/en-us/article/23788293/diablo-ii-resurrected-patch-2-4-ladder-now-live)、[2.6](https://news.blizzard.com/en-gb/article/23899624/diablo-ii-resurrected-ladder-season-three-has-concluded) 的精选规则，以及 [3.3](https://news.blizzard.com/en-gb/article/24296140/diablo-ii-resurrected-ladder-season-15-now-live) 的五件低等级暗金调整。3.3 原改动限于 Warlock 扩展天梯，本项目主动采用这些改动，不声称完整复刻该模式。

保留现有短战役经验、1pp–8pp、怪物强度、圣火、热诚、锤子和火球规则。不叠加一轮全局增伤。生成的 LoD 数据不直接修改；运行时物品目录为 `src/item-catalog-current.ts`。

## 技能

| 技能 | 本次变化 |
| --- | --- |
| 炮轰 | 武器伤害由 75% 改为 100%；准确率为 30% + 9% ×（技能等级 − 1）；多重箭每硬点 +5%、引导箭每硬点 +10% 物理伤害 |
| 多重箭 | 引导箭每硬点 +12% 物理伤害；仍保留 75% 武器伤害与单次齐射单目标命中上限 |
| 引导箭 | 每级伤害增量由 5% 改为 7%；多重箭每硬点 +12% 物理伤害 |
| 圣光弹 | 可穿透恶魔、不死生物和被转化盟友；基础伤害 +50%；移除锤子协同，保留天堂之拳协同；祈祷治疗协同由 15% 改为 20% |
| 天堂之拳 | 额外延迟由 1 秒改为 0.4 秒，仍受施法动作间隔限制；次级弹伤害恶魔与不死生物并穿透 |
| 九头海蛇 | 移除额外 2 秒延迟；上限由 3 组改为 6 组，仍持续 10 秒，超过上限替换最早一组 |
| 新星 | 起始耗蓝由 15 改为 13；静态力场每硬点 +5% 电伤 |
| 雷云风暴 | 静态力场每硬点 +7% 电伤；持续时间改为 144 + 24 ×（等级 − 1）秒 |

天堂之拳同次施法的次级弹共享命中集合，主目标只受天雷，其余每个目标最多承受一次圣光弹伤害。这是防止当前 3D 大体积目标被多弹叠伤的本地适配。圣光弹仍受墙体阻挡；玩家承伤保护不变。

## 符文之语与暗金

眼光允许弓、弩，原有长柄与法杖仍可制作。接入眼光的装备赋予双倍打击，以及新增躁动护甲赋予的回避：其他职业使用赋予等级，亚马逊对应赋予加成最高 +3；均不产生技能硬点或协同。装备不可用、换到备用组或卸下后，效果不再生效。

新增壁垒、治愈、炉火、地面、熔火五种三孔头盔，以及躁动（Hustle）三孔护甲。分别提供物理防护、净化、抗性与吸收、无法冰冻或攻速和移动。只采用功能完整的护甲版 Hustle，不添加含尚未实现加速触发的武器版。六种配方全部通过现有镶嵌、随机变量、百科和存档流程。

配方效果与镶嵌符文效果分开计算，只加一次。最终头盔拥有 20% 打击恢复、10 体力、5% 最大生命与 75%–100% 增强防御；元素头盔总抗性 40%–60%。躁动护甲为 65% 跑速、40% 攻速、20% 打击恢复、6 级回避、10 敏捷、50% 耐力消耗降低与 10 全抗。

新掉落：勇气之眼 +25% 攻速；祸根之灰移除攻速和物理增伤、增加 20% 施法速度；玛那得的治疗及墓穴之脊（Gravenspine）增加 10% 施法速度；眨眼蝙蝠的外观跑速改为 30%、增加 1 击杀回蓝。

已有暗金保留已有属性及随机记录，不重新掷值；新掉落使用新属性。已有眼光原本未结算的双倍打击，依据原随机记录恢复，不改变原有增伤、准确率等变量。角色等级、技能点与任务进度不回收、不重算。原有重置技能服务可以用于改配新协同。

## 验证与限制

`tests/modern-rules.test.ts` 检查实际命中与穿透、技能协同、海蛇上限、配方与符文加成、赋予被动、旧暗金往返及购买失败的原子性。`tests/modern-balance.test.ts` 使用合法点数、可制作眼光弓和中档装备，检查普通第三幕旧断档、三难度终章首领与三怪组合，以及 8pp 压力。

战斗模拟运行真实玩家、怪物控制器、碰撞和药剂恢复，但使用无地图障碍的开放场地和固定走位策略，不模拟随机刷装耗时，不代表真人死亡率或通关保证。天堂之拳路线对首领使用圣光弹，对怪群使用天堂之拳；海蛇与新星按各自技能定位测试。

`npm run test:modern` 覆盖桌面和手机的补给商人、底材购买、实际镶嵌眼光与壁垒、存档重载和百科底材许可。运行时支持 `BASE_URL` 和 `OUTPUT_DIR`。其余职业、随机物品变量与战斗回归沿用已有测试。
