# 关卡地图与普通箱子

25 个关卡使用每次进入重新生成的 149 × 149 战斗网格，并各自配置主路、侧室与连接图。洞窟采用不规则洞室，蛆虫巢穴收窄虫道，神秘避难所采用四向浮桥，混沌避难所采用十字翼廊，世界之石采用对称仪式长廊；其他关卡也有独立路径和地标。任务目标与箱子分布在可达支路中，原有关卡 ID、目标编号和角色通关记录保持兼容。每关的材质、建筑、照明和天气见 [五幕场景设计](scenes.md)。

角色导航使用实际碰撞体生成的半格采样图，以角色半径保留通行间隙。直达判断与路线平滑使用连续线段，转弯时提前选取可安全到达的位置，避免沿整格轴向反复折返。建筑的寻路范围不再额外向外扩张整格；实体地形边界补齐与碰撞边缘一致的可见墙面，装饰物放在边界后方，首领场地石柱也具有对应碰撞。地面未鉴定装备标签只展示底材与实际孔数。

每关放置 4 至 6 个普通箱子，五章分别为 4、4、5、5、6 个。点击箱体或标签可自动走近并打开，近距离按 F 或使用交互按钮也可打开。已探索区域的地图显示箱子位置，打开后标记变灰、箱盖保持开启；每次进入地图只能打开一次。重新进入关卡时箱子与怪物一起刷新。营地没有怪物或随机箱子。

## 地形与探索结构

地图网格从 101 扩为 149 格，扩大节点间距并增加随机侧室，角色和门洞保持原有尺度。入口仍为 `(0, 11)`。窄道出口和主路避开可碰撞装饰，怪群分布在主路与支路中，远程和支援单位位于靠后的站位。逐关设计、进入与复活规则、怪群上限和经验预算见 [随机远征与探索平衡](random-maps.md)。

## 掉落数据与规则

使用与装备目录相同的 LoD 1.13 数据版本：[`TreasureClassEx.txt`](https://github.com/fabd/diablo2/blob/e67aa992be5db412bd0437bb8afb95eedee0c9bc/code/d2_113_data/TreasureClassEx.txt) 和 [`ItemRatio.txt`](https://github.com/fabd/diablo2/blob/e67aa992be5db412bd0437bb8afb95eedee0c9bc/code/d2_113_data/ItemRatio.txt)。`scripts/import-chests.ps1` 从固定提交导入 45 个章节、难度及 A/B/C 箱子入口，递归保留 145 个可达宝藏表和 53 种杂物。生成数据位于 `src/chest-data.ts`，运行时不联网。

- 每个箱子至少掉落总计 `ceil((5 + 区域等级) × (1 + 金币获取加成 / 100))` 金币，以及一瓶可使用的生命或法力药剂。原表已生成足量金币或对应药剂时不再补发；缺少的补齐，因此不会有空箱子。
- 额外战利品继续使用原表：25% 判定跳过额外抽取，否则进行 4 次宝藏表抽取并保留 NoDrop。保底不会重抽装备或符文，最多原表 4 件加 2 份补给。保底药剂在生命、法力中等概率选择。
- 按章节、难度和区域等级选择 Chest A/B/C，再递归使用原表权重。43 种没有使用或制作功能的杂物抽中后视为空抽，不重抽装备或符文；生命、法力药剂保留。单人掉落固定按一人计算，没有多人 NoDrop 加成。
- 武器与防具按原底材等级对应的 weap/armo 宝藏组及底材 rarity 权重抽取，并排除当前未开放职业的专属底材。先确定底材，再依次判定暗金、套装、稀有和魔法品质，不会为了生成暗金而改换底材。
- 品质使用原版扩展模式的普通/职业专属 ItemRatio，以及 MF 的暗金、套装、稀有收益递减。暗金或套装必须满足同底材和等级要求；无可用物品时分别降为稀有或魔法，并保留失败品质的耐久加成。护符不能生成稀有或套装品质。
- MF 影响装备品质，不增加符文概率；金币量按区域等级及金币获取加成计算。箱子不享受首领保底、首通奖励或女伯爵专用符文奖励。

开箱与分档行为依据 [D2MOO 的原版对象操作逻辑](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/OBJECTS/ObjMode.cpp) 中 `OBJECTS_OperateFunction04_Chest`、`OBJMODE_DropFromChestTCWithQuality`；金币计算参考 [物品生成逻辑](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/ITEMS/Items.cpp)。[官方 Magic Find 说明](https://classic.battle.net/diablo2exp/items/magic/magicfind.shtml) 确认 MF 适用于箱子，不影响符文掉率。

## 适配边界

本次实现普通未上锁箱子；不包含上锁箱子的额外抽取、陷阱、闪光箱或超级箱子的特殊算法。金币和药剂保底是本项目新增规则。关卡为五章各五关的原创地图，A/B/C 分档使用本项目每章区域等级的上下界，沿用原版三段分档算法，并非逐一复刻原地图的箱子表映射。

生命与法力药剂各等级仍接入现有两种药剂计数。宝石、钥匙、卷轴、回复药剂、投掷药剂等无功能杂物已关闭掉落，旧存档中的物品仍可保存、放入仓库及出售，完整清单见 [当前物品获取范围](item-availability.md)。普通装备的劣质、超强、无形和随机孔数判定尚未实现；魔法词缀与特殊装备属性继续使用当前装备系统支持的范围，详见 [装备目录说明](item-catalog.md) 和 [词缀说明](affixes.md)。

## 精英怪

每关在普通怪群外额外生成精英，普通为 1 至 2 只、噩梦 3 至 4 只、地狱 5 至 6 只；每章前三关取下限，后两关取上限。精英分布在侧室与支路，具有金色名称、血条和脚下标记，体型为同种普通怪的 1.2 倍。营地不生成精英，重进关卡时刷新。

精英等级为区域等级 +2（最多 99），生命为同种普通怪的 2.5 / 3 / 3.5 倍，伤害为 1.25 / 1.35 / 1.45 倍，防御 1.25 倍、准确率系数 1.2、移动速度 1.1 倍。保留物种招式与抗性；精英尸体不被复活，召唤物也不会变为精英。

精英装备、符文、魔法护符分别有 55%、15%、2% 的独立掉落判定（普通怪为 16%、3.5%、0.6%）。装备品质按现有小首领品质区间判定，金币为普通怪同等级的 2 倍，药剂概率为 60%。符文仍受章节、难度和等级限制，MF 不影响符文。精英不会获得女伯爵、熔炉或章节首领专属掉落与首通奖励。

击杀精英计入普通击杀任务，并获得经验基准的 2 倍权重；不会代替守关首领、推进关卡或获得首通经验加成。已通关关卡可反复挑战，每次进入都会按所选难度重新生成精英，经验、装备和符文掉落照常结算，没有每日次数或首次击杀限制；永久任务奖励不会重复发放。

## 验证

`npm test` 覆盖补给保底、额外宝藏抽取、45 个入口及所有底材组、MF/金币加成隔离、同底材品质降级、杂物存取与存档、大地图网格坐标，以及精英数量、战斗属性、掉率和首领奖励隔离。启动开发服务器后运行 `npm run test:maps` 检查地图与开箱流程，`npm run test:elites` 检查全部 75 种关卡/难度组合的实际精英生成、可达性、精英击杀、补给落地及桌面/手机画面。
