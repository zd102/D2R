# 佣兵 · 米山

通关第一章第五关、击败安达利尔后，罗格营地开放**佣兵商人格雷兹**。已有第一章通关记录的角色会直接解锁。点击商人标签可自动走近并打开雇佣面板，靠近后也可按 F 交互。

花金币雇佣米山后，他会随玩家跨关卡、跨难度战斗，自动追击附近敌人，以双段突刺近战攻击；远离玩家时会归队。按 **O** 或点击左上角佣兵状态栏，管理装备与光环。手机可点击同一状态栏操作。

米山以近身护卫为定位：基础移速 8 格/秒，落后玩家 8 格以上时以 16 格/秒追赶。主动搜索自身 8 格内、同时位于玩家 10 格内的敌人；选中远处敌人也不会突破这一范围。优先协助范围内的当前目标，可绕墙追击；目标离开护卫范围后停止追击并跟随玩家，避免连续追入远处怪群。索敌每 0.12 秒检查、绕障路径每 0.18 秒刷新，不可达目标暂时跳过；落后超过 36 格时归队。零攻速、零武器速度修正时双段突刺间隔为 0.16 秒、组间恢复 0.8 秒；装备攻速仍缩短两段间隔与恢复，分别保留 0.1 / 0.45 秒下限。

**按住 Shift，再按 1**，消耗玩家背包计数中的一瓶生命药剂，给米山以每秒 30 点的速度恢复共 160 点生命。每次按键只使用一瓶，系统自动重复按键不会连续消耗；单按 1 仍治疗玩家。未雇佣、已阵亡、满血、无药或暂停时不消耗药剂。剩余治疗量会随存档与切图保留，死亡时清除，无法用药复活。

米山等级始终等于玩家等级，没有独立经验条。玩家升级时，存活的米山同步提升属性并恢复生命。米山击杀怪物同样计入玩家经验、击杀数与任务进度；生命偷取、击杀恢复作用于米山自身。佣兵击杀时，寻获魔法装备与额外金币属性与玩家的对应属性相加。

## 装备与光环

- 三个装备栏：武器、头盔、铠甲。武器支持非职业专属的长柄武器、长矛与标枪，标枪仅用于近战。
- 从背包装备或取回；可先将仓库中的物品移至背包。装备交换时背包放不下旧装备则整次操作取消，不丢失物品。
- 面板最大宽度 820 像素，以紧凑状态栏、装备与背包、光环技能分区。三个装备栏并排显示，默认收起详细属性，点击物品才显示词缀及穿戴后的伤害、防御、生命与吸血变化；页签支持左右方向键切换。主界面的佣兵血条与 Buff 区域自动上下排列，状态过多时可滚动查看，并避让手机首领血条和操作区。
- 检查鉴定、耐久、等级、力量与敏捷要求，装备不能依靠自身属性满足自身需求。卸下力量/敏捷装备后，不再符合需求的其他装备停止生效。
- 复用项目装备与镶嵌系统，支持伤害、防御、生命、抗性、攻速、吸血、压碎性打击、双倍打击/致命攻击、撕开伤口、元素伤害、吸收、减伤、控制、已实现的装备诅咒触发及装备光环。装备不消耗耐久。体力和法力类属性不会增加佣兵生命或提供施法资源，防止怪物自疗不适用于佣兵。
- 可随时选择祈祷、反抗、祝福瞄准、力量、神圣冰冻、荆棘之一，无需玩家学习圣骑士技能。光环持续生效，祈祷不消耗玩家法力；神圣冰冻以米山为中心减速并每两秒造成冰冷伤害，对首领的减速减半。装备提供的额外光环（例如眼光的冥思）可并存，同名光环按实际效果取较强者，避免原生光环与装备光环的不同成长曲线造成误判。
- 同名队伍增益不叠加。范围以施放者为中心计算，离开范围或米山阵亡后，其增益立即消失。玩家的队伍光环也能强化范围内的米山。

阵亡会立即保存状态、停用光环，并保留三个栏位中的装备及光环选择。回营地、切图、切难度、玩家升级、复活或重载存档均不会复活米山。必须回到佣兵商人处支付当前等级的雇佣费，才能让他重新随行；阵亡期间可以取回装备。

旧角色存档默认没有佣兵。佣兵状态包含在独立角色保存及导入导出中，并与背包、仓库、角色装备及尸体共同检查物品 ID，防止重复装备。

## 本项目平衡

参考[暴雪 Arreat Summit 的佣兵规则](https://classic.battle.net/diablo2exp/basics/hirelings.shtml)，采用沙漠佣兵的突刺、六种光环与装备类别。以下曲线是针对本项目关卡、金币和即时战斗节奏的适配值，并非原版数据复刻；按需求直接同步玩家等级、允许切换六种光环。

设玩家等级为 L：

| 项目 | 基础规则 |
| --- | --- |
| 雇佣 / 重新雇佣费 | `min(50000, 300 + 80L + 5L²)` 金币 |
| 生命 | `120 + 14×min(L,45) + 18×max(0,min(L,75)-45) + 26×max(0,L-75)` |
| 力量 / 敏捷 | `40 + 2L` / `25 + floor(1.5L)` |
| 固有防御 | `20 + 6L`，再结合敏捷、装备和光环 |
| 固有全抗 | `min(150, 15 + floor(14L/10))`，再承受普通 / 噩梦 / 地狱的 0 / 40 / 100 抗性惩罚，常规有效抗性上限 75% |
| 原生光环等级 | `min(20, 1 + floor((L - 1) / 5))`，再加装备的所有技能，总等级最多 30 |
| 突刺技能等级 | `1 + floor(L / 5)`，再加装备的所有技能 |
| 基础物理伤害 | 武器伤害乘力量及装备/光环加成，再加受攻击光环加成的固有伤害 `3 + 0.15L` 至 `5 + 0.25L`，整体乘等级伤害系数；突刺、双倍打击等随后结算 |
| 等级伤害系数 | 1–15 级 30%，15–75 级线性提升至 80%，75–99 级保持 80%；装备元素伤害、压碎性打击、触发法术和装备光环不额外乘这一物理系数 |
| 章节变化 | 生命与物理伤害不再按章节缩放，进入第五章不会突然增强，返回早期章节也不会突然减半 |
| 章节首领压力 | 五大章节首领（含使用同一定义的超级迪亚波罗）对佣兵的基础来袭伤害乘 1.5，再结算抗性、吸收与减伤 |

等级 15 / 30 / 60 / 90 的基础生命为 330 / 540 / 1020 / 1680，雇佣费为 2625 / 7200 / 23100 / 48000 金币。地狱 75 / 90 / 99 级的裸四抗为 20% / 41% / 50%，仍需装备补足，但不会永久停在负抗。米山沿用怪物等级、命中率、抗性、难度吸血折减和多人生命对应的压碎性打击规则。

前中期偏肉盾与光环辅助，固有伤害、自愈和主动追敌范围受限；后期裸装物理输出低，装备增伤、吸血、致命攻击、压碎性打击、衰老、装备光环与背信消退构成主要提升。平衡以同级正常推进、普通过渡装备为参照，不设置禁止击杀首领的硬限制；超等级回刷或特殊成型装备仍可能击败弱关卡。

六种原生光环采用独立曲线，装备赋予光环与玩家圣骑士光环保留原有数值。以下为未穿戴增加技能等级装备时的效果：

| 光环 | 米山 10 级 | 30 级 | 60 级 | 90 级 |
| --- | --- | --- | --- | --- |
| 祈祷：每两秒回血 | 3 | 6 | 13 | 23 |
| 反抗：防御提高 | 76% | 108% | 156% | 204% |
| 祝福瞄准：准确率提高 | 70% | 110% | 170% | 230% |
| 力量：物理伤害加成 | 39% | 67% | 109% | 151% |
| 神圣冰冻：减速 / 每两秒冰伤 | 20% / 4–6 | 23% / 8–11 | 29% / 14–19 | 34% / 20–26 |
| 荆棘：近战伤害反弹 / 附加固定反伤 | 90% / 4 | 130% / 11 | 190% / 21 | 250% / 32 |

祈祷每次恢复 `max(1, round(固有生命 × (0.01 + 0.0002R)))`，未加技能时约为固有生命的 1%–1.4%，用于缓慢续航，无法替代接战中的吸血与治疗。力量也强化固有物理伤害，让低伤武器阶段有可感知的收益。祝福瞄准、突刺和装备的准确率百分比相加，对恶魔或不死生物的额外准确率也会参与命中计算。

神圣冰冻的武器附加冰伤为脉冲伤害的 1.5 倍；原生光环不会额外施加通用 50% 冰缓，以免绕过自身减速曲线，装备自带冰缓仍有效。原生减速含装备技能加成最多 45%，对首领减半。荆棘按实际承受的近战物理伤害反弹并增加固定值，不反弹远程或元素攻击，受攻击者必须处于光环范围内。

辅助光环半径为 `min(20, 10 + 0.4R)`，神圣冰冻为 `min(14, 5 + 0.3R)`，R 为包含装备加成后的原生光环等级。96 级达到原生 20 级，生命恢复、冰伤与固定反伤继续随角色成长至 99 级。

## 验证

运行 `npm test`、`npm run build` 和 `npm run test:mercenary`。浏览器回归设置 `BASE_URL=http://127.0.0.1:5173/?mode=local` 明确选择本地模式，支持 `OUTPUT_DIR` 指定本次产物目录，覆盖桌面、390/360 像素手机与横屏布局、键盘页签、装备预览、商人、六种光环、战斗、死亡存档与重新雇佣。

装备实战回归使用死神的丧钟、督瑞尔的壳，以及实际镶嵌制作的壁垒、眼光，检查增伤、吸血、衰老触发、按等级生命、无法冰冻、减伤、生命恢复、致命攻击及冥思；同时检查取回装备后属性撤销、预览与实际穿戴一致，以及属性不会串到玩家身上。光环测试遍历 1–99 级成长，并验证实际脉冲、首领减速、范围、死亡失效与同名光环选择。

成长回归覆盖 1–99 级连续性、跨章节属性一致、近身索敌与脱战，以及同级普通过渡装备六种光环对代表性普通／噩梦首领的接战压力测试。压力测试使用真实佣兵攻击、抗性、回血、诅咒及触发结算，首领每秒一次攻击，玩家不攻击、不喂药，最多 120 秒；它是可重复的数值基准，不是完整地图或首领 AI 的通关证明。后期使用三个随机种子比较 90 级裸装和丧钟＋背信＋壁垒的输出及生存，并另行验证压碎性打击、致命攻击与装备光环。
