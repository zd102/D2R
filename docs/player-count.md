# 1pp–8pp 人数难度

按 Esc，在「人数难度」中选择 1pp–8pp。默认 1pp，与普通／噩梦／地狱独立；每个角色分别保存，旧存档默认为 1pp。

| 设置 | 怪物生命／经验 | 噩梦、地狱伤害／命中 | 单人掉落档位 |
| --- | --- | --- | --- |
| 1pp | ×1 | ×1 | 1 |
| 2pp | ×1.5 | ×1.0625 | 1 |
| 3pp | ×2 | ×1.125 | 2 |
| 4pp | ×2.5 | ×1.1875 | 2 |
| 5pp | ×3 | ×1.25 | 3 |
| 6pp | ×3.5 | ×1.3125 | 3 |
| 7pp | ×4 | ×1.375 | 4 |
| 8pp | ×4.5 | ×1.4375 | 4 |

普通难度不增加伤害和命中。人数不改变怪物等级、防御、抗性、数量或移动速度；角色原有经验惩罚仍生效。普通怪、精英、首领及隐藏区域均使用人数生命倍率，召唤怪仍不提供经验和掉落。压碎性打击按怪物生成时的生命倍率折算，避免伤害随人数同比增加。

怪物生成时固定生命、伤害、命中和经验倍率；已生成怪物不因切换设置恢复生命或重新缩放。重新进入关卡后按新设置生成怪物。掉落按击杀或开箱时的当前设置结算，已掉落物品不会重掷。设置保存失败则回退，通关奖励的领取次数不受人数影响。

## 掉落计算与适配边界

单人模拟人数按非同队玩家计算，`N = floor((pp + 1) / 2)`。有 `NoDrop` 权重的表按下式调整，保持非空条目的相对权重：

```text
q = (NoDrop / (NoDrop + ItemWeight)) ^ N
NewNoDrop = floor(ItemWeight * q / (1 - q))
```

`NoDrop = 0` 的必掉项目不会增加。3、5、7pp 降低不掉落概率，2、4、6、8pp 与前一档掉落相同。人数不增加 MF、物品等级、宝物等级上限、单件品质概率或每堆金币数量。

本项目沿用现有简化怪物掉落表：普通怪和章节首领的装备／符文／护符／药水独立类别，把原概率转换为总权重 1000 的空／非空选择后应用上述公式。精英、守关首领的常规掉落不加成人数；章节首领原有必掉装备、首通奖励、专属物品抽取、女伯爵额外符文、奶牛关保底和超级迪亚波罗保底保持原规则。因此具体掉率与原版完整 TreasureClassEx、多次抽取和女伯爵六件上限并非逐项复刻。

宝箱已有原版权重表，直接调整每层表的 NoDrop；保留原有 25% 空箱检查、抽取次数、不可用物品过滤与最低补给。
