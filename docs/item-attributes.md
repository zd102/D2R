# 装备属性与战斗结算核对

## 数据口径

以项目固定的 LoD 1.13 原始表为准，不混入 D2R 后续赛季属性。核对范围为 499 个原始底材代码、506 件暗金/套装、78 个符文之语、33 枚符文以及套装奖励。暗金/套装在生成时、符文之语在制作完成时按原始区间随机；图鉴使用稳定中间档示例并列出变量范围，蓝黄随机词缀保持已有独立掷值。见 [固定装备随机变量](item-rolls.md)。

新生成底材的伤害、需求、速度、格挡、耐久和等级统一读取原表，旧名称与占格兼容保留。暗金、套装、符文之语不再用旧手写修正值覆盖原表。具有增强防御的暗金/套装与蓝黄防具使用底材最大防御 +1。普通白底材防御取区间中值，符文之语沿用所选底材。

## 已修正

| 属性 | 实际行为 |
| --- | --- |
| 火、冰、电、毒技能增伤 | 同类装备百分比相加；进入对应伤害结算，不增幅物理或魔法伤害。元素灵气武器附伤保留原作的技能端与近战端增伤；毒伤按命中时的属性快照结算 |
| 降低敌人元素抗性 | 先计算审判是否以 1/5 效果破免，再应用装备减抗；装备减抗不能单独破免，抗性最低 -100。审判不作用于毒或魔法 |
| 吸收 | 火、冰、电百分比吸收上限 40%，抗性后先百分比再固定吸收；固定魔法吸收独立。先补血再扣剩余伤害，满血不会凭空储存治疗 |
| 每级属性 | 补齐力量、敏捷、体力、MF、金币、致命攻击、对恶魔/不死生物伤害与准确率、吸收、耐力等；按角色等级取整；装备不能靠自身力量/敏捷满足穿戴条件 |
| 武器与防具增伤/防御 | 武器 ED 作用于底材，非武器 ED 加入技能/力量区；每级增强伤害只作用于武器最大伤害。单件套装 ED 留在该件上，武器上的增强防御作为全局防御加成 |
| 符文 | Tal 为约 75 毒伤/5 秒，Ral 5-30 火伤，Ort 1-50 电伤，Thul 3-14 冰伤/3 秒；Sol 仅 +9 最小伤害，Eld 防具效果为降低耐力消耗。所有符文之语的符文与配方奖励各计算一次 |
| 装备灵气 | 接入原表全部 18 条灵气属性。相同装备灵气先合并等级，与主动同名灵气取较高等级；不同灵气并存。物品灵气不受 +所有技能提升，保留角色硬点协同；损坏、未鉴定、未满足需求或切至副手时停用 |
| 单项圣骑士技能 | 原表单项技能可在零投入时使用、绑定并保存；卸下装备后失效。火焰技能加成作用于圣火。其他职业技能在图鉴标出职业限制 |
| 装备诅咒 | 20 条原表触发记录接入伤害加深、衰老、偷取生命、削弱。使用原概率/技能等级，区分攻击、击中、受击；同一怪物只保留最后一种诅咒，到期撤销。偷取生命对盾击与普通吸血无效的不死生物仍有效，不触发法术连锁 |
| 其他战斗效果 | 附加魔法伤害、减慢目标（首领最高 50%）、命中降低防御、远程/近战专用防御、闪电反伤、自动修复、击杀回血、击杀恶魔回血、经验加成与尸体平静生效 |
| 撕开伤口/压碎打击 | 撕开伤口按原始五段等级公式持续 8 秒，首领减半；压碎打击在普通伤害前结算，负物抗不放大其伤害。牺牲和盾击不触发致命攻击 |
| 远程装备 | 弓弩/投掷使用实际飞行、原始远程伤害与属性系数；穿透、魔法箭、爆炸箭、数量恢复及数量上限生效，远程压碎打击比例减半，见 [远程说明](ranged-combat.md) |
| 百分比生命/法力 | 装备体力、精力及每级生命/法力不再额外乘生命/法力上限百分比。受伤转法力只处理物理伤害 |

套装单件按不同部件计数，西刚也使用原表；单件增强防御和武器增强伤害不会错误施加到其他部位。

## 存档兼容

旧暗金、套装和完整符文之语按名称或稳定 ID 迁移到当前固定属性，并记录 `catalogVersion: 1`。已有底材数值、物品 ID、占格、孔数、符文、耐久、位置与蓝黄随机词缀保留；已镶嵌刻面补齐增伤/减抗并补记原始 ID。迁移不重新掉落装备，也不重新抽取蓝黄词缀。

随机变量更新后，新生成的目录装备使用 `catalogVersion: 2`，保存逐条掷值与实际属性；旧目录装备保留数值。鉴定、图鉴、装备切换、重载和导入不会重新随机；随机刻面的属性在镶嵌和读取宿主时保持不变。

## 尚未复刻

运行 `node scripts/item-attribute-report.ts` 可复查全部 3,788 条原始属性记录（包含套装候选奖励）：3,336 条可转换/支持，189 条为其他职业，241 条未接入，22 条为原表禁用或纯外观标记。这里是属性记录映射统计，不能解释为原版机制完全还原率；特殊 `add func=1` 的指定部件奖励仍未结算。

尚未接入的属性主要是其他触发法术、技能聚气、职业外技能（包括传送）、无形、亡灵复活和商店折扣。图鉴与装备详情会显示这些原始效果并标注“未生效”；其他职业加成另标职业限制。不会用额外 ED 或全抗代替缺失法术。普通职业专属底材的随机自动词缀/白杖技能、雇佣兵及其他职业远程技能仍未实现。照亮范围已连接角色灯光，以原作基础 13、最大 18 的比例适配场景距离。

战斗仍沿用项目的圣骑士技能平衡、场景尺寸、怪物 HP 和攻速模型。冻结/致盲采用既有简化持续时间，远程攻击间隔和弹药补给按本地场景适配；其他近战武器的特殊属性系数仍未全面校对。因此不是 1:1 原版战斗引擎声明。

## 验证

`tests/item-effects.test.ts` 核对完整固定属性、符文之语双部位、免疫边界、吸收顺序、装备灵气、每级属性与幂等存档迁移。`tests/combat.test.ts` 验证真实战斗控制器中的增伤、毒伤、诅咒、盾击偷取生命、减速到期及修复。`tests/item-effects-browser.mjs` 验证桌面/手机图鉴、未生效标签及生产击杀函数的生命/法力/经验奖励不重复发放。

全量单元测试和生产构建通过。八组合法参考配装首领对战均通过：普通安达利尔约 7-8 秒，普通巴尔约 12-14 秒，噩梦巴尔约 20-27 秒，地狱巴尔近战约 47 秒、祝福之锤约 38 秒；均未超出原定 150 秒、每种最多 8 瓶药水的预算。这是中等装备的回归保障，不代表所有顶级装备组合已穷举验证。
