# 超级暗金基础强度与特色

本项目的 23 只超级暗金使用独立预算。按同区域、同难度怪物池的黄色精英计算，各项属性分别取最高基础值，再乘下表系数。词缀、灵气、技能倍率在战斗时另算；多人生命和伤害倍率只应用一次。神殿用复生战士、毁灭仆从作为参照，神殿本身不生成精英和冠军。

该预算修复超级暗金绕过噩梦／地狱野外攻击强化，以及奶牛之王直接用普通奶牛基础生命的问题。所有超级暗金的原始生命高于同区着魔冠军；基础攻击至少达到同区最高基础攻击精英，但仍低于同区最高攻击狂战士冠军。实际威胁还取决于抗性、攻击节奏、词缀和技能，不能把基础伤害当作 DPS。章节首领和超级迪亚波罗保留原有预算。

尼拉塞克最多保有两个活仆从或未消耗的仆从尸体。击杀仆从不产生经验、掉落、任务进度；尸体最多保留 12 秒，拥有者死亡后清理。尸爆消耗一次尸体，有预警，造成火焰和物理伤害且不做防御命中检定。玩家可用救赎、尸爆、死亡卫哨等消耗尸体，或用安息装备阻止留尸；寻找物品／药剂可清除该尸体，但不产生奖励。仆从自然到期不留尸体。

## 回归验证

- `npm test`：包含 23 只 × 3 难度 × 8 人数的属性边界、冠军差异、抗性及特色技能回归。
- `npm run build`：客户端及服务端 TypeScript 检查、生产构建。
- `node tests/super-uniques-browser.mjs`：正式生成逻辑的 2,694 个超级暗金／精英／冠军实例。
- `node tests/nihlathak-browser.mjs`：三难度入口、仆从留尸、尸爆、安息、无奖励和重复进入。
- `npm run test:elites`：三难度 75 张关卡的生成与精英战斗、桌面／移动端回归。

浏览器验证使用本地模式：`BASE_URL=http://127.0.0.1:5173/?mode=local`；在 PowerShell 中用 `$env:BASE_URL='http://127.0.0.1:5173/?mode=local'` 设置。
