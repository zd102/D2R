# 远程武器与远程技能

实现日期：2026-09-09。本文件描述本地项目“黯蚀 II · ECLIPSE”的实际行为。数据基线为《毁灭之王》1.13，射程、速度、动画和补给经济按当前三维关卡适配。

## 武器与操作

| 武器 | 普通攻击 | 消耗 | 伤害依据 |
| --- | --- | --- | --- |
| 弓 | 发射箭矢 | 箭矢储备 | 原始双手伤害，敏捷系数 100% |
| 弩 | 发射弩矢，基础攻击间隔比弓长 | 弩矢储备 | 原始双手伤害，敏捷系数 100% |
| 标枪 | 投出标枪 | 当前武器数量 | 原始投掷伤害，通用标枪力量/敏捷各 75% |
| 飞刀 | 投出飞刀 | 当前武器数量 | 原始投掷伤害，力量/敏捷各 75% |
| 飞斧 | 投出飞斧 | 当前武器数量 | 原始投掷伤害，力量/敏捷各 75% |

72 个普通、扩展、精华与亚马逊专属底材的远程数据从固定原表导入。亚马逊专属标枪使用原表力量 80%、敏捷 50% 的例外，但仍受当前圣骑士职业限制，不会因此变为可穿戴物品。投掷武器的装备详情显示投掷伤害与无限弹药；角色面板按当前普通攻击显示伤害和速度。

点击敌人会自动接近至可射击位置，进入射程且视线通畅后攻击。Shift + 左键可原地朝鼠标方向连续射击；触屏攻击保留自动选敌。远程普通攻击的选敌射程为 14 个场景单位，投射物发出后不追踪目标；移动敌人能够躲开，也可能由路径上更近的敌人先承受攻击。

弓、弩、标枪、飞刀和飞斧都有对应手持模型；弓弩使用持弓/抬弩和回弹动作，发射有独立音效。装备和切换武器组后模型随有效武器更新。损坏、未鉴定、需求未满足或职业不匹配的武器不启用远程攻击。

弓弩不能施放牺牲、热诚、复仇、转化、冲锋。这些限制在扣除法力和进入攻击间隔前检查。投掷武器仍可使用相容的近战技能；这些技能使用近战伤害且不消耗投掷数量。重击与神圣之盾仍要求有效盾牌，重击伤害只使用力量加成，不继承投掷武器的敏捷系数。

## 无限弹药

- 自 2026-09-10 起，弓、弩、标枪、飞刀和飞斧默认无限弹药，普通攻击与亚马逊远程技能均不消耗箭矢或投掷数量，状态栏显示 `∞`。
- 旧存档的弹药和数量即使为 0，也可以直接攻击；原有字段保留用于兼容，不再限制发射或产生补充费用。
- 旅者补给不再出售弹药，背包不再提供箭筒补充按钮。既有箭筒杂物仍可保存、转移和出售。
- 装备维修仅恢复耐久；补充数量和增加数量上限属性不再影响持续攻击能力。
- 武器类型、装备要求、耐久、技能法力及攻击间隔仍然生效。

无限弹药是本项目的操作简化，不复刻原作箭筒与投掷堆叠管理。

## 飞行、碰撞与伤害

远程武器在发射时生成场景投射物，命中后才执行武器伤害流程。内部将更新切为不超过 0.01 秒的小步，再检查每段飞行路径和障碍网格；较大的更新时间不会让箭矢跨过薄墙。多目标按路径由近及远处理，每枚投射物对同一敌人至多判定一次。

武器命中继续使用准确率、防御、等级与 5%-95% 命中边界。物理伤害、元素附伤、毒、致命攻击、压碎打击、吸取、击退、减速和已有装备诅咒接入实际命中。远程压碎打击使用近战比例的一半，并保留物抗处理。纯法术投射物不额外触发这些武器效果。

发射时记录进攻数值及触发装备快照，换武器、卸装备或修改技能不会把后来的伤害加成追溯到在途投射物。目标当前抗性、诅咒和生死状态仍在命中时判断；灵气作用距离沿用当前角色位置。元素灵气武器附伤在远程攻击中不会再额外套用近战端的同类技能增伤。

| 原始装备属性 | 接入行为 |
| --- | --- |
| `pierce` | 命中后按百分比穿透，最高 100%；未命中的箭可继续飞行，但不再次命中同一目标 |
| `magicarrow` | 弓弩的普通攻击变为相应等级魔法箭，不消耗箭矢；增加固定伤害与准确率，将部分物理伤害转为魔法伤害 |
| `explosivearrow` | 弓弩普通攻击命中目标或墙壁后爆炸，半径 2.5；火焰范围伤害使用技能等级、装备火伤和圣火附伤，受视线与抗性限制 |
| `rep-quant` | 有效穿戴时按时间恢复该件投掷武器数量 |
| `stack` | 增加该件投掷武器的数量上限 |

同一配装同时授予魔法箭与爆炸箭时，爆炸箭优先，同样不消耗弹药。爆炸火伤使用独立范围判定，物理攻击未通过准确率检查仍可爆炸；主目标不重复获得直接火伤。范围伤害不向周围目标扩散吸血、武器触发或压碎打击。穿透爆炸箭可以在不同命中点分别爆炸，重叠范围内的目标可以再次受到不同爆炸的伤害。

导入属性报告由 3,305 条支持、272 条未接入，更新为 3,336 条支持、241 条未接入，其余 189 条职业限制与 22 条禁用/外观标记不变。这是 3,788 条记录的映射统计，不是完整原版引擎还原率。

## 圣骑士远程技能

| 技能 | 当前规则 |
| --- | --- |
| 圣光弹 | 直线飞行，碰撞墙体终止；只伤害不死生物，能够治疗路径上被转化的盟友，穿过其他活体目标 |
| 祝福之锤 | 施法时按瞄准点校准螺旋初始角度，飞行后不追踪；沿弯曲路径检测墙体和敌人，同一锤子对同一目标只伤害一次 |
| 天堂之拳 | 先检查目标、12 单位射程与视线；主目标受到闪电伤害，再向落点附近不死生物发射实际飞行的圣光弹；保留一秒施放延迟 |

圣光弹、天堂之拳的目标规则沿用经典 LoD，不引入官方重制版 2.4 的恶魔受伤规则。天堂之拳次级弹按落点时的目标方向发射，不做原作完整导引/寻敌模拟；次级弹不会治疗盟友。空目标、超出射程或隔墙的直接天堂之拳不会扣除法力或设置延迟。

尚未加入亚马逊弓弩/标枪技能树、多重箭、炮轰、导引箭、连锁闪电、法师远程技能和装备授予的其他法术。原始 `Missiles.txt`、`AnimData`、逐职业动作帧及全部碰撞例外也未完整移植；当前弓弩攻击间隔受武器速度、IAS、狂热和冰冷影响，但不宣称原版逐帧一致。

## 存档与代码入口

`HeroState.ammo` 保留旧存档的两类储备，`Item.quantity` 保存每件投掷武器数量。无限弹药下新角色不再赠送储备，旧存档缺少储备时默认为零，缺少投掷数量时使用该件上限；明确保存的储备值保持不变。读取时限制非法数值，现有角色、物品 ID、耐久、孔数、镶嵌和武器组继续保留。旧目录装备补齐新属性，无需重新掉落。

| 文件 | 职责 |
| --- | --- |
| [import-ranged.ps1](../scripts/import-ranged.ps1) / [ranged-data.ts](../src/ranged-data.ts) | 固定原始版本与 72 个底材远程元数据 |
| [ranged.ts](../src/ranged.ts) | 无限弹药状态与视线检测 |
| [combat.ts](../src/combat.ts) | 发射、伤害快照、轨迹、碰撞、穿透、爆炸和圣光弹 |
| [model.ts](../src/model.ts) / [items.ts](../src/items.ts) | 数值、数量、维修、存档兼容与属性迁移 |
| [world.ts](../src/world.ts) / [ui.ts](../src/ui.ts) / [character-ui.ts](../src/character-ui.ts) | 武器模型、动作、状态栏和补给界面 |
