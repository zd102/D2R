# 蓝黄装备与护身符词缀

本次改动只对之后生成的魔法、稀有装备与护身符生效。旧物品不重掷、不削减已有数值；背包、仓库、尸体和备用武器组继续兼容原存档。暗金、套装、符文之语及普通底材的既有生成规则不在本次重做范围内。

## 数据与生成

- 数据来自原版 LoD 1.13 的 `MagicPrefix.txt`、`MagicSuffix.txt`、`Weapons.txt`、`Armor.txt`、`Misc.txt` 与 `ItemTypes.txt`，固定到 [fabd/diablo2 的 e67aa99 提交](https://github.com/fabd/diablo2/tree/e67aa992be5db412bd0437bb8afb95eedee0c9bc/code/d2_113_data)。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/import-affixes.ps1` 可重新生成 `src/affix-data.ts`。运行游戏不需要访问外网。
- 导入器保留 757 条本项目能完整结算的有效词缀记录，包括圣骑士、亚马逊和法师的职业/技能系加成，以及原始等级、需求等级、频率、组别、适用/排除类型和每条属性的变量；实际可抽取范围还会按当前底材筛选。废弃行、零权重行、等级超过 99 的行不会掉落。
- 蓝装：50% 只有后缀，25% 只有前缀，25% 前后缀各一个。黄装：3/4/5/6 个词缀的权重为 1/2/3/2，每个词缀前后缀各半概率，最多三前缀、三后缀。同组互斥；复合词缀只占一个名额。数值按本档上下界均匀掷整数，不再随关卡等级倍增。
- 根据原始底材质量等级 qlvl、掉落物品等级 ilvl 计算词缀等级 alvl。先令 `L = max(clamp(ilvl, 1, 99), qlvl)`；无魔法等级加成时，若 `L < 99 - floor(qlvl / 2)`，则 `alvl = L - floor(qlvl / 2)`，否则 `alvl = 2 * L - 99`；有加成时取 `L + magicLevel`，最后限制到 1–99。需求等级取底材和实际抽中词缀需求的最大值，不再按区域等级乘 0.7。
- 生成结构及稀有词缀数量权重核对了 [D2MOO 的 ItemsMagic.cpp](https://github.com/ThePhrozenKeep/D2MOO/blob/master/source/D2Game/src/ITEMS/ItemsMagic.cpp)。每级属性换算遵循 `ItemStatCost.txt`：伤害、防御、生命、法力按八分之一单位；准确率及其百分比按二分之一单位。
- 现有中文底材名称通过独立映射读取原始 qlvl，不改写旧底材伤害。部分项目历史名称/属性并非完全对应原作，例如“锐利之柱”映射 Colossus Voulge，“重扣带”映射 Belt，“轻扣带”映射 Demonhide Sash；映射以现有属性和底材定位为依据。

典型结果：残酷增强伤害为 201–300%，黄装也能抽中其稀有版本，但解锁词缀等级不同；愚人是每级 0.5 最大伤害与 16.5 准确率；偏向是 20% 格挡与 30% 快速格挡；普通头盔不能抽头环专属施法或职业技能词缀，戒指没有圣骑士技能，项链不再出现跑速。蓝装可抽三/四孔词缀，黄装最多两孔，并受底材与物品等级孔数上限限制，均不能制作符文之语。

## 护身符

三种尺寸分别为 1×1 小护身符、1×2 大型护身符、1×3 超大型护身符，原始 qlvl 分别为 28、14、1。三者均为蓝色品质，遵守同样的前后缀规则，不能跨尺寸抽词缀。技能板支持圣骑士、亚马逊和法师共九个技能系，只有对应职业生效。

| 例子 | 精确范围/上限 | 最低掉落物品等级 | 角色需求等级 |
| --- | --- | --- | --- |
| 精良小护身符 | 1–3 最大伤害、10–20 准确率，一个复合前缀 | 42 | 21 |
| 活力小护身符 | 16–20 生命 | 61 | 39 |
| 闪耀小护身符 | 3–5 所有抗性 | 47 | 25 |
| 好运小护身符 | 6–7 寻获魔法装备 | 61 | 33 |
| 活力大型护身符最高档 | 31–35 生命 | 81 | 66 |
| 技能超大型护身符 | +1 战斗 / 攻击灵气 / 防御灵气 | 50 | 42 |
| 活力超大型护身符最高可掉落档 | 41–45 生命 | 91 | 83 |
| 瘟疫小护身符 | 175 毒伤，持续 6 秒 | 94 | 80 |

因此可产生 3/20/20 小护符、5 全抗/7 寻魔小护符或技能/45 生命大板，但不能在小护符上同时生成生命与寻魔后缀，也不会生成不可掉落的 46–50 生命大板。大型及超大型护符另有寻魔前缀，不能把小护符的后缀互斥结论套用于全部尺寸。

属性仅在背包中、已鉴定且满足角色等级时生效；仓库和未鉴定护符不参与结算。物品详情显示掷出的数值及本档变量范围，复合元素词缀合并显示最小/最大伤害，毒伤显示总伤害与持续秒数。

## 战斗与掉率

新增词缀的火焰、冰冷、闪电伤害按最小/最大值掷实际伤害。新毒伤使用每帧 1/256 伤害单位、每秒 25 帧：同一件物品的前后缀速率与持续时间分别相加，多件物品速率相加、持续时间取平均。例如瘟疫/炭疽小护符为 451 毒伤、12 秒。毒伤按时间和毒抗扣血，重复命中刷新而非无限叠加，较弱毒伤不能覆盖仍在生效的较强毒伤。盾击不携带元素/毒伤，物理免疫不再阻止已命中攻击附带的元素结算。旧装备与符文的简化固定元素数值保持原结算，不追溯转换。

| 来源 | 新护身符掉率 | 原护身符掉率 |
| --- | --- | --- |
| 普通怪物 | 0.6% | 1.8% |
| 小首领 | 2.5% | 8% |
| 章节首领 | 4% | 12% |

装备、符文与金币概率不变。护符尺寸权重为小型 50%、大型 25%、超大型 25%；寻魔不改变护符概率、尺寸、词缀池或词缀档位。概率仍是适合本项目 25 关节奏的独立掉落判定，**不是原版完整 Treasure Class 掉落表**。

本次没有加入其他职业技能、聚气、触发法术、自动修复、自动补充数量、照亮范围、按时段变化词缀；含有未实现效果的复合词缀整条排除，而非保留名称却省略效果。圣骑士盾的原生自动词缀、权杖单项技能、无形装备和珠宝仍属后续范围。中文词缀名作了本地化适配，不是完整官方语言包。
