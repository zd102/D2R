# 安雅赌博商人

普通难度全部 25 关通关后，安雅出现在罗格营地。已有通关存档无需重打；回营地即可看到「赌博商人」，点击或触摸标签自动寻路，靠近后也可按 F 交互。

货单固定包含戒指、项链及 12 件随机普通底材，不重复。免费刷新货单；购买不会移除商品，可连续赌博同一底材。购买前只显示底材和价格，购买后立即鉴定并收入背包。金币不足、背包空间不足、未解锁或不在商人处均不能交易；保存失败时回滚本次金币与物品。

赌博窗口直接展示背包网格。点击物品查看属性，可按标价出售或存入私人仓库，无需退出赌博窗口；新购买的物品会立即显示。鼠标拖动、手机长按拖动均可调整背包位置，也可聚焦物品后按空格拾起、方向键移动、回车放下。出售、存仓和换位在保存失败时回滚。桌面商品与背包并排，窄屏上下排列。

货单采用紧凑卡片，桌面每行 5 件、手机竖屏每行 4 件，价格按钮直接购买；完整规则可点击「赌博规则」展开。卡片显示底材级别，当前货单均为普通底材；购买后可能升级为拓展或精英，选中背包物品可查看实际级别。底材级别与魔法、稀有等物品品质分别计算。

规则参考[暴雪 Arreat Summit 赌博说明](https://classic.battle.net/diablo2exp/basics/gambling.shtml)：

- 本项目将稀有品质概率从 10% 提高至 20%：魔法 79.85%、稀有 20%、套装 0.1%、暗金 0.05%，不受难度、人数、魔法寻获影响。
- 物品等级为角色等级 −5 至 +4，限制在 5～99；底材品质等级不高于角色等级 +4 才进入货单候选池。
- 戒指、项链、头环、宝冠、通用武器与防具、刺客爪可赌博。职业专属装备（爪除外）、法杖、魔杖、权杖、护身符、珠宝和符文不供应。
- 普通底材有机会升级：先检查精英概率 `max(0, (物品等级 − 精英底材等级) × 0.33% + 1%)`，再检查扩展概率 `max(0, (物品等级 − 扩展底材等级) × 0.9% + 1%)`。
- 暗金、套装使用本项目现有图鉴、等级门槛和权重。无符合条件的同底材暗金时降为稀有；无套装时降为魔法。赌博不会产出无形装备。

项目适配：戒指基础价 50,000，项链 63,000 金币；其他装备基础价为 `1,000 + 角色等级 × 300 + 普通底材等级 × 100`，均享受现有商店折扣。这不是原版全部底材的逐项报价复刻。货单在本次营地访问期间保留，切换场景或重新进入游戏后重新生成；已购买物品正常保存。

验证：`npm test`、`npm run build`、`npm run test:gambling`。浏览器回归默认使用 `http://127.0.0.1:5173`，支持 `BASE_URL`，覆盖桌面和手机端的解锁、寻路、刷新、购买、连续购买、背包选择、出售、存仓、鼠标／触摸／键盘换位、存档失败回滚和重载。
