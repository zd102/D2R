# 界面设计与操作

界面以暗黑 2 的黑铁、旧铜、暗红与羊皮纸色为基础。标题采用衬线字体，说明与数值使用清楚的中文界面字体；装备保留独立的品质颜色，增益、减益和物品比较仍以文字与状态标记辅助区分。

## 统一界面

- 角色选择与创建：远征主题背景文案、职业玩法说明、随选择更新的初始生命和法力、名称长度提示，以及独立存档说明。
- 战斗 HUD：金属镶边的红蓝资源球、药剂色彩区分、经验和耐力条、桌面菜单快捷键，以及统一的地图、任务、交互和掉落标签。
- 行囊、私人仓库与共享仓库：装备凹槽、物品格、完整属性、比较信息和固定操作区共用视觉样式；触屏继续使用分区切换与拖动辅助栏。
- 角色与技能：属性数值、可投入点数、技能等级、前置条件和绑定菜单具有一致的层级和选中状态。
- 任务、章节、地图、补给、神秘传送阵、死亡与百科：统一标题、边框、按钮、列表和提示样式。
- 暂停菜单：旅程操作和游戏设置分区，提供可展开的操作手册。危险的角色删除界面首先聚焦“保留角色”。

## 键盘与无障碍

- 打开面板后，Tab / Shift+Tab 在可见且可操作的控件之间循环，包含展开说明的 summary，排除隐藏文件输入、禁用按钮和未选中的同组单选框。
- 分类标签支持左右方向键及 Home / End，切换后焦点跟随选中的标签。
- 职业单选框支持原生方向键，初始属性通过实时区域播报。
- 空格可激活按钮和展开操作手册；分配属性或刷新物品后保留合理的焦点，关闭面板后返回原入口。
- Tab 仍可在游戏中打开地图，再按一次关闭地图。Esc 返回冒险。
- 尊重系统的减少动态效果与强制颜色设置；不再通过 viewport 禁止浏览器缩放。

## 实现边界

布局规则位于 [ui-layout.css](../src/ui-layout.css)，物品专属布局位于 [item-details.css](../src/item-details.css)。[ui-theme.css](../src/ui-theme.css) 最后加载，统一外观并保留已有的物品拖动状态。共用框架和键盘焦点逻辑位于 [ui-components.ts](../src/ui-components.ts)。

本次界面重构不改变职业数值、战斗规则、物品属性或存档格式。初始职业数据直接读取现有职业定义。

## 验证

`npm run test:ui` 覆盖桌面、平板、手机竖屏和横屏的布局与主要交互，包含神秘传送阵、存档管理、百科及死亡界面。新增的 [键盘回归](../tests/ui-accessibility-browser.mjs) 验证职业选择、实时属性、空格操作、刷新后焦点、分类导航、操作手册、焦点循环与返回、删除界面的初始焦点和减少动态效果。

截图默认写入各测试的 `.verification` 目录，可通过 `OUTPUT_DIR` 为 UI 测试指定独立目录。
