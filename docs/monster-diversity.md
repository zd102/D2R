# 怪物物种差异

本项目以传统五幕怪物机制为依据，对38种基础怪物分别配置攻防、准确率、攻击冷却、警戒、冰冷有效率、回血和抗性。具体数值属于本项目战斗预算适配，不是原版数据表的逐帧移植。三难度生命曲线、人数规则、物品和存档格式沿用既有实现；怪物抗性仍封顶85%，不产生伤害免疫。

## 数值与进攻节奏

[monster-traits.ts](../src/monster-traits.ts) 保存每个物种的配置和玩家可见说明，[balance.ts](../src/balance.ts) 应用攻防、命中和抗性，[monster-combat.ts](../src/monster-combat.ts) 应用行为与招式。百科使用同一个 `monsterAttackSpec` 函数显示物种招式及实际基础技能冷却；前摇、技能冷却和招式间恢复是不同概念。

所有以下倍率叠加于现有区域、难度、人数及阶级规则：

- 沉沦魔伤害×0.8、防御×0.65、命中×0.8；僵尸伤害×1.35，普通重击前摇0.65秒、冷却×1.3。
- 罗格命中×1.3；女猎人命中×1.25、冷却×0.9；骷髅法师防御×0.6。
- 厄运骑士伤害×1.2、防御×1.5、命中×1.2；死亡之王伤害×1.35、命中×1.25，噩梦与地狱的狂乱附加20%魔法伤害。
- 物种警戒系数为0.8～1.15，乘以三难度12／15／18格基础接敌距离；丢失视线仍受记忆、脱战距离限制。
- 普通冰冷减速按物种和难度计算；地狱电鬼与冰川恶兽不受普通冰冷减速，但其他减速来源仍按各自规则生效。
- 山羊、蜘蛛、甲虫、吸血鬼等拥有少量持续恢复；议会保持每秒1%。只在激活、敌对且非召唤状态恢复，毒伤和禁止治疗有效。
- 各物种拥有不同的抗性曲线。安达利尔火抗固定-50%，保留火焰弱点；不统一增加所有怪物的生命。

## 招牌机制与应对

| 物种 | 实现 | 应对与限制 |
|---|---|---|
| 沉沦魔／巫师 | 惊逃、火球、匹配尸体复活；高难度沉沦魔近战附带火伤 | 优先击杀后排；保持已有复活次数与召唤上限 |
| 僵尸／羊头人 | 缓慢而更重的挥击；羊头人有少量恢复 | 躲抬手，不站桩换血 |
| 骷髅／燃烧死者 | 物理或火抗分化；燃烧死者按远程单位站位 | 使用不同元素或压进射程 |
| 罗格／女猎人／剥皮者 | 准确射击、短退和不同偏好距离 | 用墙和侧移切断射线 |
| 幽灵 | 追踪最后目击位置时，可穿越最长6格内有可行出口的障碍 | 不隔墙发现目标或攻击；连续移动穿行，出口四周检查碰撞；受控、转化或失去追踪时回到入口 |
| 腐尸 | 近战附毒，死亡后0.4秒预警，留下半径2格、持续3秒的毒云 | 离开尸体范围；墙壁阻挡伤害 |
| 解开者／剥皮巫师 | 远程复活；分别具有近身毒息、火流 | 引导站定，可以打断 |
| 甲虫 | 受击充能弹，三难度反击冷却1.8／1.3／0.9秒；与原本攻击同时预警 | 避免近身高频攻击；重复受击不能绕过冷却 |
| 沙虫／血肉复生者 | 喷吐与有限繁殖，独立防御、射程和恢复 | 切断母体；幼体不继续繁殖或提供奖励 |
| 蝮蛇／复生战士 | 中距冲锋，命中附带击退 | 横移，利用墙角截断冲锋 |
| 蜘蛛 | 近战附毒、较短警戒，低于35%生命时短退 | 追击受伤目标以阻止恢复 |
| 冥河娃娃 | 死亡0.55秒预警后发生半径2.4格物理爆炸 | 伤害按怪物伤害预算×1.5／1.8／2.1，非最大生命或人数生命倍率；每次爆炸结算一次；转化及召唤娃娃不爆炸 |
| 吸血鬼／议会 | 陨火、火墙、多头蛇与恢复，法术轮换 | 移出预警区，用毒或禁止治疗 |
| 厄运／遗忘骑士 | 冰伤近战配合伤害加深、衰老、骸骨弹 | 优先清理施咒后排 |
| 电鬼 | 13格直线闪电，0.75秒预警，沿途人物及召唤物均受威胁 | 横移、堆电抗；束线截断到墙前，受控可中断 |
| 乌达尔／毁灭仆从 | 高命中重击与击退 | 保留后撤空间 |
| 邪魔之王／冰川恶兽 | 火焰／寒冰定向吐息 | 绕侧或打断；寒冰恶兽的普通冰冷反应很弱 |
| 冰封爬行者 | 寒冰喷吐和冲锋 | 避免减速后被追上 |
| 小妖 | 3.8格内尝试闪烁，0.55秒预警，基础冷却7秒 | 目的地必须可行且可见；不回血，不连闪，可打断 |
| 奴役者 | 0.9秒预警督战，治疗7格内可见恶魔8%生命；加攻速20%、追击速度15%，持续5秒 | 不治疗自己、首领、召唤物或其他指挥者；毒／禁止治疗阻止回血；击杀、转化指挥者或脱离范围解除加速 |
| 女妖 | 根据生命／法力关系施加鲜血法力或防御诅咒 | 看诅咒后决定是否继续施法 |
| 死亡之王／狂信者 | 狂乱追击，各自拥有独立伤害和命中 | 控制后拉开距离，别让其持续贴身 |
| 奶牛 | 改为慢速重型普攻，保留厚血和密集围攻 | 拉成长队，避免被包围 |

都瑞尔采用可复现的偏好序列（三次戳刺、两次重击、一次普攻），仍服从距离与独立冷却。巴尔法力裂隙削去当前法力一半，直接伤害系数降为0.85以配合资源压力；半血幻象和其他首领技能仍保留原有适配。

## 怪群变化

第五幕普通难度保持原怪物池。噩梦每关加入一种客串，地狱加入第二种；不增加每群2～3只的数量预算：

| 区域 | 噩梦新增 | 地狱再新增 |
|---|---|---|
| 血腥丘陵 | 腐化罗格 | 黑暗一族 |
| 冰冻高地 | 燃烧死者 | 死亡甲虫 |
| 冰河 | 幽灵 | 腐尸 |
| 亚瑞特之巅 | 利爪蝮蛇 | 鲜血之王 |
| 世界之石大殿 | 遗忘骑士 | 污染怪 |

随机种子与难度共同决定编队；部分怪群优先安排前排，含复活单位的编队尽量补入其匹配同伴。区域基础经验预算保持原怪物池权重，个体取整及精英物种变化允许通关等级出现约一级波动。百科标注客串物种的难度限制。

## 验证与边界

`npm test` 包含物种数值、死亡效果、墙体遮挡、幽灵出口与受控恢复、小妖打断、督战治疗限制、反击冷却、客串编队和通关战斗预算。`npm run test:monster-diversity` 在真实浏览器中检查38种物种在三个难度的生成，以及招牌效果的渲染和结算；`npm run test:monster-skills` 覆盖章节首领，地图和场景回归检查编队变化。

受伤后0.2秒保护、同一齐射对玩家只结算一次、85%抗性上限和召唤总量限制继续生效。尚未复制所有原版隐藏判定、完整怪物亚种、巴尔五波、三先祖同时作战、小妖骑乘和奴役者变异自爆兵。电鬼保留可见模型和预警；幽灵穿行采用短距安全出口适配。

机制依据：[沉沦魔](https://classic.battle.net/diablo2exp/monsters/act1-fallen.shtml)、[幽灵](https://classic.battle.net/diablo2exp/monsters/act1-Wraith.shtml)、[腐尸](https://classic.battle.net/diablo2exp/monsters/act2-mummy.shtml)、[高等木乃伊](https://classic.battle.net/diablo2exp/monsters/act2-greatermummy.shtml)、[娃娃](https://classic.battle.net/diablo2exp/monsters/act3-bonefetish.shtml)、[电鬼](https://classic.battle.net/diablo2exp/monsters/act5g-willowisp.shtml)、[奴役者](https://classic.battle.net/diablo2exp/monsters/act5-overseer.shtml)、[小妖](https://classic.battle.net/diablo2exp/monsters/act5-demonimp.shtml)、[第五幕客串](https://classic.battle.net/diablo2exp/monsters/act5.shtml)。
