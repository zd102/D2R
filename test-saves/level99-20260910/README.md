# 99 级三职业本地测试存档

这三个 JSON 文件可直接从游戏角色选择页点击右上角“导入角色存档”，选择文件，再点击“导入为新角色”。导入后选择角色并进入旅程，从营地远征传送阵可选择任意已通关关卡。

共同状态：99 级；本职业全部 30 个技能硬点各 20；力量、敏捷、体力、精力的基础值各 999；另有 999 未分配属性点；普通／噩梦／地狱各 25 关全部通关。金币 9,999,999，生命／法力药剂各 99，资源全满，装备全部已鉴定、满耐久，目录可变属性取上限。装备与护符加成后面板属性会高于基础的 999。

第二套放在角色私人仓库（I → 仓库），不是营地共享仓库，也不是按 X 切换的备用武器组。换玩法时将仓库装备取回并逐件穿戴；同名物品也有独立 ID。亚马逊、法师还附带对应第二玩法的三块技能／45 生命大板，换装时用它们替换背包内的三块主玩法技能板。圣骑士两套均使用战斗技能板。

背包右侧预留 4×4 空间供取回装备和更换双手武器。建议每换好一件，就将替换下来的原装备存入私人仓库，再取下一件。三个文件均已通过实际导入、属性保留、仓库换装和技能释放检查。

存档专为本项目的测试数值与已实现机制制作，不代表正常升级可以获得 600 个技能硬点。未使用尚未实现的战争召唤战吼或谜团跨职业传送作为 BD 核心。洗点会按游戏正常规则重置属性、技能；可再次导入原文件恢复这些测试值。
